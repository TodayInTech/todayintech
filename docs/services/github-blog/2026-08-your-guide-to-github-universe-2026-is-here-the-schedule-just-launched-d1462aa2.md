# Your guide to GitHub Universe 2026 is here: The schedule just launched!

> GitHub Blog · 2026-08-13 · Event/Conference

---

GitHub Universe 2026 일정이 공개됐다. 10월 28~29일 샌프란시스코 Fort Mason Center에서 열리는 이틀간의 행사는 AMD, Figma, NVIDIA, Coinbase, Anthropic, OpenAI 등 업계 전문가들이 참여해 AI 기반 개발 생산성·보안·운영 사례를 다룬다. 조기 등록(8월 19일 이전)으로 $300 할인 혜택과 단체 할인, 현장 데모와 Ship &amp; Tell 세션, 파트너 부스 등을 통해 최신 툴과 실무 워크플로를 직접 체험할 수 있다. 추가로 GitHub HQ에서의 Day of Learning(추가 $50) 및 인증 시험 바우처($30) 구매 옵션도 제공된다.
프로그램은 실무 중심 워크숍과 데모에 무게를 뒀다. Copilot 구성으로 복잡한 업무를 맡기는 방법, OpenAI·Claude·Gemini 등 여러 모델을 대상으로 한 Copilot 평가·벤치마크 프레임워크, 작은 단위로 나누어 검토·병합하는 스택형 Pull Request 시연 등 실전 적용 가능한 세션이 포함된다. 또한 호스티드 MCP 서버 앞에 아이덴티티 인식 프록시를 두어 에이전트별 세분화된 권한을 부여하는 패턴, GitHub 내 50여 개 서비스에 에이전트를 적용해 이슈 분류·초안 PR 작성까지 자동화한 에이전트 파이프라인의 사례 발표 등은 대규모 운영에서의 자동화·검증·권한 설계 관점에서 특히 주목할 만하다. 커뮤니티·오픈소스·AI 채택 전략을 다루는 토론과 투표형 세션도 마련돼 있어, 현업에서 AI 도입을 고민하는 팀에게 실행 가능한 인사이트를 제공한다.
