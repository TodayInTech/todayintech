# Game Off 2026: The theme is SHIFT

> GitHub Blog · 2026-11-01 · Community / 이벤트

---

GitHub 블로그(작성자: Lee Reilly)가 14번째 연례 게임잼 **Game Off 2026**의 주제를 ‘SHIFT’로 발표했다. 참가자는 기어 전환, 관점 전환, 차원·비트 이동 등 'SHIFT'를 자유롭게 해석해 게임을 제작하면 된다. 제출 마감은 **2026-12-01 13:37 PST**이며, 투표는 마감 후 진행되어 **2027-01-01 13:37 PST**에 종료된다.

## 참여 방법 및 규칙
참가자는 개인 또는 팀으로 참여할 수 있으며, 게임 소스코드는 반드시 **공개 GitHub 저장소**에 보관해야 한다. 제출은 itch.io의 Game Off 2026 페이지에서 이루어지며(itch.io에 GitHub 계정으로 로그인 가능), GitHub에 코드를 푸시하는 것만으로는 자동 제출이 되지 않으므로 주의가 필요하다. 대회 측은 프로젝트를 대체로 잼 기간 내에 제작할 것을 권장하되 템플릿·스타터 프로젝트 사용을 허용하고, 라이선스는 자유롭게 선택할 수 있다.

AI 사용은 허용되며, 제출 시 AI 사용 여부를 묻는 항목이 있어 다른 참가자가 제작 방식을 이해할 수 있도록 한다. 심사·투표는 참가자들이 직접 플레이하고 평가하는 방식이며, 평가 항목은 **전체, 게임성, 그래픽, 오디오, 혁신성, 주제 해석**으로 나뉜다.

초보자를 위한 권장 엔진과 도구 목록도 함께 제시되어 있어 Godot, Unity, Unreal Engine, Phaser, Pygame, Bevy 등 다양한 옵션을 활용해 개발할 수 있다. 운영진의 조언으로는 하나의 핵심 메커니즘과 한 레벨을 먼저 완성해 확장해 나가라는 팁이 명시되어 있어 기간 내 프로토타입 완성에 초점을 두는 것이 실무적으로 유리하다.

제안된 제출 아이디어와 규칙은 공지에 명시된 내용만을 기반으로 정리했으며, 참가 절차와 마감 시간은 정확한 제출을 위해 원문 공지의 시간을 따르는 것이 필요하다.
