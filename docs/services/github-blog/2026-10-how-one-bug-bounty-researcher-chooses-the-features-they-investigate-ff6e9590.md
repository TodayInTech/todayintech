# How one bug bounty researcher chooses the features they investigate

> GitHub Blog · 2026-10-08 · Security

---

GitHub Bug Bounty 팀이 사이버보안 인식의 달을 맞아 VIP 연구원 @vaib25vicky를 조명합니다. 지난 수년간 전 세계 연구자들이 취약점을 찾아내 플랫폼을 안전하게 만들었고, 특히 Copilot 등 AI 기반 기능이 늘어나는 상황에서 전통적·신흥 공격 표면을 모두 다루는 연구의 중요성이 커졌다는 점을 강조합니다. 올해부터는 제출 횟이 아닌 '제출 품질'에 보상하는 방향으로 바운티 테이블을 재구성했고, 지속적으로 수준 높은 성과를 보이는 연구자를 초대하는 영구 초대형 VIP 프로그램을 도입했습니다. VIP는 최대 3만 달러 이상의 상금, 처리 속도 우대, 베타 기능 사전 제공 등 실질적 인센티브를 받으며, 초대 기준으로는 치명적 1건·높음 2건·중간 4건·낮음 7건의 해결된 리포트 등 실적 요건이 명시되어 있습니다.
조명 대상 연구자 @vaib25vicky는 권한 및 접근 통제 분야를 전문으로 삼아 복잡한 기능을 깊게 파고드는 방식으로 의미 있는 이슈를 찾아냈습니다. 그는 목표 대상을 복잡하고 이해하기 어려운 기능 중심으로 고르고, 해당 기능을 계속 사용·테스트하며 '잘못된 동작'을 포착해 다양한 버그 클래스를 검사한다고 설명합니다. AI는 생산성 향상에 도움을 주는 보조 도구로 활용하지만 산출물을 반드시 연구자가 검증해야 한다고 강조하며, AI·웹 취약점의 본질은 여전히 권한 문제·약한 가드레일·간과된 기능에서 나온다고 봅니다. GitHub은 연구자 커뮤니티와의 협력을 독려하며, 발견된 취약점은 HackerOne을 통해 신고할 것을 권합니다.
