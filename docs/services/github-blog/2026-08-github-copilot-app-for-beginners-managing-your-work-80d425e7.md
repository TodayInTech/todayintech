# GitHub Copilot app for Beginners: Managing your work

> GitHub Blog · 2026-08-19 · Developer Tools

---

GitHub의 Copilot 앱 초심자 시리즈 세 번째 글은 프로젝트에서 발생하는 여러 작업을 한곳에서 정리하는 방법에 초점을 맞춘다. My work 패널은 사용자가 앱 내에서 건드린 저장소를 기준으로 자동 필터된 풀 리퀘스트와 이슈를 한눈에 보여주며, All·Active·Review requests·Done 같은 기본 뷰로 지금 진행 중인 일과 완료된 일을 구분할 수 있게 설계돼 있다. 기본 카드형 리스트 외에 테이블 뷰를 제공해 컬럼 선택·이동·크기 조정이 가능하고, 보기·정렬 옵션을 저장하거나 원래 상태로 되돌릴 수 있어 개인 작업 흐름에 맞춘 인터페이스 조정이 쉽다.
실무적 핵심은 이슈나 PR을 직접 선택해 Copilot 세션을 시작할 수 있다는 점이다. 여러 항목을 묶어 개별 세션을 만들거나, 관련 이슈를 하나의 세션으로 번들링하는 방식으로 작업 단위를 유연하게 구성할 수 있으며 세션이 참조하는 리포지토리를 변경하는 기능은 이슈가 호스팅된 저장소와 코드가 있는 저장소가 다른 경우에도 유용하다. 또한 사용자가 직접 새 뷰를 만들어 Is: Issue 혹은 Assignee: Me 같은 필터를 적용하고 빠르게 이슈를 생성해 즉시 세션 문맥으로 옮길 수 있어, 에이전트 기반 작업을 관리하고 우선순위를 유지하는 데 실무적 가치를 제공한다. 자세한 사용 흐름과 예시는 시리즈의 다른 영상과 gh.io/app에서 확인하도록 안내하고 있다.
