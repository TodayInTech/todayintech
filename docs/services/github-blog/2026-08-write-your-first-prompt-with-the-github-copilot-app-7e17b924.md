# Write your first prompt with the GitHub Copilot app

> GitHub Blog · 2026-08-12 · AI &amp; ML

---

새로운 AI 도구 앞에서 막막함을 느끼는 개발자를 위해 GitHub Copilot 앱 사용을 단계적으로 안내한다. 핵심은 완벽한 프롬프트가 아니라 '시작 가능한 설명'을 주는 것이다. 먼저 리포지토리나 로컬 폴더를 세션에 연결해 Copilot이 실제 코드와 파일을 볼 수 있게 하고, 간단한 자연어로 변경 의도를 적는다(예: "게임 목록에 most-funded 정렬 옵션 추가"). Copilot은 프로젝트를 살펴보고 관련 코드를 찾아 변경 작업을 시도하며, 첫 시도가 기대와 다르면 추가 세부사항을 덧붙여 반복적으로 다듬으면 된다. 별도의 문법을 익힐 필요 없이 현재 아는 만큼 서술하는 것이 권장된다.
작업 성격에 따라 모델을 선택해 더 복잡한 추론을 요구하는 업무에 맞출 수 있고, 기본 모델부터 시작해 필요 시 전환하면 된다. 텍스트 입력뿐 아니라 음성 입력을 지원해 긴 요청이나 생각을 말로 정리한 뒤 편집해 전송할 수 있으며, 에이전트 선택이나 원격 제어 같은 세션 설정으로 작업 실행 방식을 바꿀 수 있다. 이들 옵션은 첫 프롬프트 전 반드시 설정해야 할 항목이 아니라, 사용하면서 자연스럽게 채택할 수 있는 도구로 소개되어 있어 개발자가 적은 부담으로 Copilot을 실무 흐름에 통합하도록 돕는다.
