# The Anthropic Economic Index connector

> Anthropic Blog · 2026-07-22 · 인공지능/데이터 도구

---

Anthropic이 자사 경제지표인 Anthropic Economic Index를 Claude 대화형 모델과 바로 연결해 데이터에 직접 질의할 수 있는 'Anthropic Economic Index connector'를 공개했다. 이 인덱스는 AI가 경제에서 어떻게 사용되는지를 측정하는 데이터셋으로, 연구자·언론·정책입안자들에게 이미 활용돼 왔고 이제는 누구나 claude.ai의 커넥터 메뉴에서 해당 커넥터를 활성화해 별도 설치 없이 일반 대화에서 즉시 질의할 수 있다. 사용 예로는 “어떤 직업이 AI를 가장 많이 쓰나?”, “콜로라도 주민들이 Claude를 주로 어떻게 쓰나?”, “교사들이 Claude로 어떤 과업을 수행하나?” 같은 질문을 들 수 있으며, Claude는 답변에 인덱스 데이터를 근거로 제시하고 요청 시 근거 데이터도 보여준다.
기술적 의미는 대화형 AI를 통해 실사용 패턴 데이터에 접근하고 탐색하는 흐름을 가속화한다는 점이다. 대화 인터페이스에서 광범위한 산업·직무별 활용 사례와 자동화 추세를 손쉽게 조회할 수 있어 연구·현장 의사결정에 유용하다. 다만 인덱스는 노동시장 전체가 아니라 Claude 사용 패턴을 반영하는 데이터임을 명시하고 있으며, 원문은 데이터와 한계를 함께 보여주도록 설계돼 있다고 밝힌다. 전체 데이터셋은 웹에 무료로 공개되어 있어 깊이 있는 후속 분석도 가능하다.
