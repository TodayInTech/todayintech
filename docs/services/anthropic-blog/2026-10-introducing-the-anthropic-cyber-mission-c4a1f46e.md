# Introducing the Anthropic Cyber Mission

> Anthropic Blog · 2026-10-08 · 사이버보안/운영기술

---

Anthropic은 전력망·수자원·교통 등 실물 리스크로 직결되는 운영기술(OT)과 오픈소스 소프트웨어를 겨냥한 장기 공약인 Anthropic Cyber Mission을 출범시켰다. 핵심 시작점으로는 최첨단 Claude 모델과 현장 엔지니어, 위협 연구를 결합해 운영기술을 보호하는 Critical Infrastructure Defense Program(CIDP)과 오픈소스 프로젝트를 정기적으로 스캔하는 OSS Scanner를 내세운다. CIDP는 Accenture, Booz Allen, CrowdStrike, Deloitte, Dragos, Hitachi, Nozomi Networks, Palo Alto Networks, PwC, Rockwell Automation 등 운영기술 보안에 관여하는 서비스·제조사들과 협업해, 오프라인으로 바로 패치하기 어려운 장비와 공정에서 모델 기반 분석으로 취약점을 찾아 우선순위를 정하고 수리 지원을 제공하는 것을 목표로 한다. 또한 Project Glasswing을 사이버검증(Cyber Verification) 프로그램으로 통합해 더 많은 방어자에게 고급 모델 접근을 제공하고, Anthropic 엔지니어 인력을 현장에 배치하며 자금과 도구를 지원한다고 밝혔다.
오픈소스 측면에서는 Project Glasswing에서 수백 개 프로젝트를 스캔한 경험을 바탕으로 OSS Scanner를 도입해, 가입한 프로젝트에 대해 모델이 생성한 취약점 보고서(개념증명·설명·수정 제안 포함)를 주기적으로 무료로 제공한다. 이 보고서는 사람의 사전 검토 없이 전송되므로 빠르지만 일부 부정확성(예: 잘못된 심각도 평가)을 포함할 수 있으며, 초기 진양성률을 90% 이상으로 기대한다고 명시했다. Anthropic은 자동화된 트리아주·패치 가속화, 코드 강화 방법 연구 등으로 확장하려 하고, Python Software Foundation·OpenSSF·Apache 재단 등에 자금을 지원하며 Defender Advantage Fund(0xDAF)를 통해 시범 사업을 후원한다고 밝혔다. 한편 회사는 공격자들이 AI를 이용해 기계 속도로 노출을 찾는 반면, 취약점 검증·공개·수정은 느리게 진행되며 운영기술 환경에서는 수십 년이 걸리는 경우도 있다는 한계를 인정하고, 향후 몇 년에 걸쳐 방어를 AI 중심으로 강화하겠다는 전망을 제시했다.
