# Introducing Claude Sonnet 4.5

> Anthropic Blog · 2026-07-22 · AI 모델/제품 출시

---

Anthropic이 공개한 Claude Sonnet 4.5는 코딩·에이전트 구축·컴퓨터 사용 능력에서 크게 향상된 차세대 모델이라고 소개된다. 회사는 Sonnet 4.5가 장기 맥락에서의 집중력을 크게 늘려 30시간 이상 복잡한 작업을 유지할 수 있고, 수학·추론 능력에서도 실질적 개선을 보였다고 밝힌다. 제품쪽 업데이트로는 Claude Code에 작업 저장과 롤백이 가능한 체크포인트, 터미널 인터페이스 개편, 네이티브 VS Code 확장 추가, API에 컨텍스트 편집과 확장된 메모리 도구가 포함되며, 앱 내에서 코드 실행과 스프레드시트·슬라이드·문서 생성을 대화 내에서 직접 처리하는 기능을 도입했다. 또한 개발자용 Claude Agent SDK를 공개해 회사가 내부에서 사용한 에이전트 인프라를 외부에 제공한다.
기술적 성능 근거도 구체적이다. SWE-bench Verified에서 200K thinking 설정 기준으로 보고한 점수는 77.2%(1M 구성은 78.2%이나 최근 추론 이슈로 200K를 주지표로 제시)이고, OSWorld에서는 61.4%로 이전 Sonnet 4(42.2%) 대비 큰 폭으로 상승했다. 내부 코드 편집 벤치마크에서 오류율을 9%에서 0%로 낮췄고, 보안 에이전트 사례에서는 취약점 처리 시간 평균을 44% 줄이고 정확도는 25% 개선했다고 보고한다. 안전성 측면에서는 ASL-3 등급과 CBRN 관련 분류기를 포함한 보호책을 적용했으며, 잘못된 차단(false positive)은 초기 설명 이후 10배, Opus 4 대비 2배 개선되었다고 명시한다. 요약하면 Sonnet 4.5는 실사용 도구 통합, 장기 작업 처리, 에이전트 인프라 제공과 더불어 여러 벤치마크와 내부 지표로 성능·안전성이 뒷받침된 모델로, 개발자들에게 즉시 사용 가능한 업그레이드로 권장된다.
