# Introducing Sonnet 4.6

> Anthropic Blog · 2026-07-21 · 제품·모델 업데이트

---

Anthropic의 Claude Sonnet 4.6은 Sonnet 계열의 기능을 전반적으로 끌어올린 메이저 업데이트로 소개된다. 모델은 코딩, 컴퓨터 사용, 장기적 추론, 에이전트 계획, 지식 업무, 디자인 등에서 성능 향상을 보이며 베타로 1M 토큰 컨텍스트 창을 제공한다. Free와 Pro 플랜에서 기본 모델로 배포되며 요금은 Sonnet 4.5와 동일하다. 초기 사용자 피드백과 내부 평가에서는 코드 변경 시 맥락을 더 잘 읽고 중복을 줄이며 다단계 작업을 더 일관되게 수행하는 것으로 보고됐다. 컴퓨터 사용 측면에서는 OSWorld 등 벤치마크와 실제 작업에서 스프레드시트 탐색이나 다중 탭 작업 병행 같은 인간 수준의 역량에 근접한 사례가 관찰되었지만, 여전히 최상위 인간 숙련자에는 못 미친다는 점도 명시된다. 또한 프롬프트 인젝션 등 위험을 인지하고 저항성 개선을 진행한 결과, 전반적 안전성은 동종 모델과 비교해 동등하거나 우수하다고 평가되었다.
성능 비교에서 Sonnet 4.6은 여러 평가에서 Opus급 성능에 접근하거나 일부 작업에서는 동등한 결과를 보였으며, OfficeQA(문서 이해), 보험 벤치마크(94%) 등에서 의미 있는 개선을 보여 문서 추론·업무 자동화에 실무적 이익을 제공한다. Vending-Bench Arena 같은 장기 전략 평가에서는 초기 투자 후 후반에 수익성으로 전환하는 전략을 통해 경쟁 우위를 확보했으며, Rakuten AI·Box 등의 시험에서 iOS 코드 품질, 프론트엔드 시각 산출물, 재무 분석 등 실사용 측면에서 개선이 보고되었다. 제품 측면에서는 컨텍스트 압축(컴팩션), 웹 검색·페치 자동 코드 생성, 코드 실행·메모리·툴 호출 등 기능들이 가용화되어 API와 Excel용 커넥터 등으로 실무에 바로 적용 가능한 점이 기술적 의미가 크다. 가격 대비 성능이 크게 향상되어 Opus 계열의 고비용 모델을 대체할 실용적 대안으로 자리매김할 가능성이 크지만, 실제 현장 적용에서는 여전히 사람 수준 검증과 프롬프트 인젝션 대비가 요구된다는 점을 함께 고려해야 한다.
