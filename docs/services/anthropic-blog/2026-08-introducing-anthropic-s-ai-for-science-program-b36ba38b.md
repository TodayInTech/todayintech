# Introducing Anthropic's AI for Science Program

> Anthropic Blog · 2026-08-27 · 연구·프로그램 발표

---

Anthropic이 연구자들에게 자사 API를 통한 계산 자원을 무료로 제공해 과학 연구를 가속하겠다는 ‘AI for Science’ 프로그램을 발표했다. 이번 이니셔티브는 특히 생물학·생명과학 분야에 초점을 두고 고영향 연구를 지원하기 위해 API 크레딧을 제공하겠다는 내용으로, 연구 제안의 과학적 기여도와 잠재적 영향, AI가 연구를 실질적으로 가속할 수 있는지 여부를 기준으로 수혜자를 선정할 계획이라고 밝히고 있다. 회사는 고급 추론과 언어 능력이 복잡한 과학 데이터 분석, 가설 생성, 실험 설계, 결과 커뮤니케이션을 단축해 약물 발견, 유전 데이터 분석, 농업 생산성 향상 등에서 실효를 낼 수 있다고 설명한다.
프로그램 신청은 연구기관 소속 연구자를 대상으로 하며, 심사는 관련 분야 전문가들이 참여해 진행된다. 발표문에는 모델 하드웨어 표준(Model Hardware Standard, MHS)의 리서치 프리뷰를 일부 연구실과 제조업체에 개방한다는 내용과 함께, 전 세계 연구자 10,000명에게 Claude를 무상 제공하는 조치도 포함돼 있다. 검증된 책임연구자(PI)는 Claude Team 구독 권한을 얻고 팀원들을 표준 요금제 좌석에 무료로 추가하거나 프리미엄 좌석을 월 $15로 최대 1년간 이용할 수 있도록 한다. 이 제안들은 AI 도구를 실제 실험·자동화 환경과 연결하고 계산적 지원을 넓힘으로써 실험 설계와 분석의 속도와 범위를 확장할 가능성이 있어 기술적·운영상 함의를 갖는다.
