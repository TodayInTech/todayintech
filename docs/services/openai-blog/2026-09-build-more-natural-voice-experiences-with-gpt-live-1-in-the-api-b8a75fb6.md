# Build more natural voice experiences with GPT‑Live‑1 in the API

> OpenAI Blog · 2026-09-10 · Product

---

피드 기준으로는 OpenAI가 'GPT‑Live‑1'을 API로 내놓아 자연스럽고 전이중(full‑duplex) 음성 대화를 지원한다고 합니다. 제공된 요약에서는 지침 이행 능력이 강화되었고 맞춤 음성(custom voices)과 전화 연동(telephony support) 같은 기능을 포함한다고만 밝혀져 있어, 제품의 핵심 방향이 실시간 음성 상호작용 쪽으로 이동하고 있음을 알 수 있습니다. 다만 메타데이터만으로는 지연 시간, 스트리밍 프로토콜, 보안·인증 방식 같은 기술적 세부는 확인되지 않습니다.
기술적 관점에서 보면 전이중 음성 처리는 양방향 실시간 상호작용을 구현하려는 애플리케이션에 의미가 큽니다. 피드에 제시된 내용만 보면 대화형 비서·콜센터 자동화·인터랙티브 음성 인터페이스에 적용될 여지가 있으나, 실제 통합의 난이도나 운영 비용, 품질 보증을 위한 측정 지표 등은 원문과 추가 문서로 확인해야 정확한 평가가 가능합니다.
