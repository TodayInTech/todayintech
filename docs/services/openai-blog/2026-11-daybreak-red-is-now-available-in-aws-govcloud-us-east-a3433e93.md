# Daybreak Red is now available in AWS GovCloud (US-East)

> OpenAI Blog · 2026-11-04 · Product

---

피드 기준으로는 OpenAI가 2026-11-04자 블로그에서 **Daybreak Red**(GPT-5.6 Cyber)를 AWS GovCloud (US‑East)에서 이용 가능하게 했다고 밝혔다. 제공 경로는 **Amazon Bedrock**이며, 서비스 대상은 '승인된 고객(approved customers)'으로 한정되고 사용 목적은 '권한 있는 사이버보안 작업(authorized cybersecurity work)'으로 표기되어 있다.

해당 피드 메타데이터만 보면 배포 위치(US‑East), 모델 명칭(GPT-5.6 Cyber / Daybreak Red), 전달 채널(Amazon Bedrock)과 대상·용도 제한이라는 핵심 사실이 확인된다. 접근 절차·가격·구체적 보안 통제 등 세부 정보는 메타데이터에 포함되지 않아 자세한 내용과 이용 요건은 원문이나 제공자 확인이 필요하다.
