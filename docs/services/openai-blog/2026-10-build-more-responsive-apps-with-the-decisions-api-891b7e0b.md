# Build more responsive apps with the Decisions API

> OpenAI Blog · 2026-10-22 · Product

---

OpenAI가 **GPT‑6 Luna 기반 Decisions API**를 일반 제공(가용)으로 발표했다. 이 API는 단답형·구조화된 결정을 빠르게 내리도록 설계되어, Responses API 기반 GPT‑6 Luna보다 **최대 10배 빠른** 처리 속도를 목표로 한다고 명시되어 있다.

## 결정형 응답과 결과 타입
Decisions API는 개발자가 '질문'과 허용된 응답을 정의하면 컨텍스트(텍스트·이미지·네이티브 JSON)를 바탕으로 세 가지 형태로 결과를 반환한다. **probability**(조건이 참일 확률, 0–1), **choice**(사전 정의한 옵션 중 선택 — 응답에 확률과 신뢰도 포함), **score**(룰렛의 수준들에 대해 확률 가중 평균으로 계산된 점수)로, 이들 타입은 분류·라우팅·우선순위 판단·상태 평가 등 다양한 결정 흐름에 바로 연결할 수 있다.

## 성능·비용·배포 모델
문서에는 지연(latency)과 비용 절감이 강조되어 있으며, 입력 토큰만 과금되는 모델을 채택한다. 가격은 **입력 토큰 100만 토큰당 $0.10**, 캐시된 입력은 **$0.01/백만 토큰**으로 표기돼 있다(30분·12시간 캐시 쓰기 옵션 언급). 출력 토큰 요금은 없으며, 지역 처리(미국·EU)와 조건부로 **Zero Data Retention**이 제공된다. 또한 프롬프트 캐싱, GPT‑Live의 네이티브 통합, 네이티브 JSON 입력 및 이미지 포함 지시문, 요청당 **최대 400개 질문**(이전 한도의 두 배) 등 실무에서 응답 재사용 및 실시간 상호작용을 개선하는 기능이 추가됐다.

## GPT‑Live 통합과 실시간 애플리케이션
GPT‑Live와의 네이티브 통합으로 음성·대화형 세션 중 즉각적 결정을 내릴 수 있다. 문서 예시에는 트랜스크립트 업데이트를 통해 아바타의 표정을 결정하거나, 고객지원 대화에서 명확화 질문·전달·에스컬레이션 여부를 판단하는 흐름을 연결하는 방식이 소개되어 있다. OpenAI 내부팀과 고객 사례도 분류·응답 시간 단축·비용 귀속 같은 적용 사례를 제시한다.

## 실무적 의미
이 API는 '자주 반복되는 작고 구조화된 결정'을 애플리케이션 레벨에서 실시간으로 자동화하려는 곳에 적합하다. 개발자는 우선 하나의 반복 결정부터 정의해 테스트하고, Decisions Playground나 개발자 가이드를 통해 텍스트·이미지·JSON 사례로 검증하라고 문서는 권장한다. 지역 인퍼런스 거주 옵션과 캐싱 비용 구조는 규정 준수·지연·운영비용 고려에 직접적 영향을 준다.
