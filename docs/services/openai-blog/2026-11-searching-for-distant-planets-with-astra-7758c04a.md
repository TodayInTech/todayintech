# Searching for distant planets with Astra

> OpenAI Blog · 2026-11-24 · Science

---

두 아마추어 연구자가 OpenAI의 Codex와 Astra를 활용해 공개 망원경 데이터를 스캔해 잠재적 외계행성 후보를 찾아냈다. 이 사례는 AI 기반 도구가 시민과학의 데이터 탐색 능력을 확장한 구체적 증거를 제공한다.

## Codex 파이프라인과 케플러 데이터
Kevin Bond는 Codex로 약 **100,000개 별**의 케플러 관측을 대상으로 검색 파이프라인을 만들었다. Codex를 이용해 기존에 발표된 신호 검출 방법들을 비교·조합하고 코드 변경을 테스트했으며, 첫 단계 에이전트는 라이트커브(밝기 시간 그래프)를 스캔해 유력 신호를 골라내고, 두 번째 에이전트가 후보군에 대해 더 정밀한 검사를 수행했다. 이 검색은 **200개가 넘는 신호**를 플래그했고 그중 **10개는 이미 확인된 행성**이었다. 두 개의 주목할 만한 후보는 다음과 같다: KIC 5689121에서 **13.8일 주기**, 관측된 감광량으로 추정하면 약 **지구 지름의 2.4배** 수준; KIC 6691030에서 **4.8일 주기**, 넵튠보다 작은 크기와 일치한다. Bond가 연락한 SETI Institute 천문학자가 독립 검색에서 이들 신호 중 두 개를 동일하게 찾았다.

## Astra로 설계한 대규모 탐색과 TESS 제출
Ethan Byrd는 Astra를 사용해 탐색 전략을 설계하고 공개 아카이브(주로 TESS 관측 포함)를 대상으로 두 가지 검색을 실행했다. 하나는 광범위 후보 탐색, 다른 하나는 거주가능영역에 초점을 맞춘다. Byrd의 초기 탐색은 **49개 후보**를 제시했고, 그중 하나는 TESS 미션 팀에 전달되어 추가 분석을 기다리고 있으며 추가 후보 두 건은 제출 대기 중이다. Byrd가 다룬 데이터 규모는 약 **1,900만 개 별**에 달한다고 보고되었다.

## 검증 경로와 실무적 의미
문헌적·통계적 검토와 후속 관측이 필수적이다. 전형적 검증 절차는 반복 트랜싯 관측으로 주기성 확인, 다른 관측기법(예: 별의 복동요동을 측정하는 방사속도(radial velocity))으로 질량·원인 판별, 그리고 동료심사 출판을 통해 커뮤니티 검증을 거친다. 기사 근거는 트랜싯과 유사한 신호를 만들 수 있는 대체 원인(겹치는 별, 망원경 계측 변화 등)을 명시하며, 최종 확인에는 수개월~수년이 걸릴 수 있다고 밝힌다.

## 의미와 제한
사실관계: Bond의 검색에서 제시된 특정 별(식별자와 주기, 크기 추정), Byrd의 후보 수(49개)와 TESS 제출 사실, SETI의 독립적 재발견 결과가 근거에 있다. 해석: AI 에이전트는 코드 작성·방법 비교·후보 선별에서 효율을 높여 시민 연구자가 '케플러 보너스 카탈로그' 같은 데이터 집합을 더 깊게 탐사할 수 있게 했다. 하지만 근거 문서도 명시하듯 후보는 아직 확정된 행성이 아니며 추가 관측과 통계적·물리적 검증이 필요하다.

관심 있는 개인은 NASA의 Exoplanet Watch, AAVSO의 Exoplanet Observing Program, Unistellar Network 등의 시민참여 프로그램을 통해 데이터 요청이나 관측 참여가 가능하다. 부가적으로 글은 2026년 11월 19일 기준으로 NASA Exoplanet Archive에서 카탈로그 스냅샷을 참조해 시각화에 사용했다고 밝힌다.
