# Virgin Atlantic sharpens customer journeys with ChatGPT Work

> OpenAI Blog · 2026-08-10 · 엔터프라이즈 AI

---

피드 기준으로는 Virgin Atlantic이 ChatGPT Work를 도입해 연구·제품 기획·의사결정 과정을 가속화하고, 팀들이 고객 여정 전반의 신호를 연결하도록 돕고 있다고 전해진다. OpenAI 블로그의 요약은 이 도구가 고객 경험의 여러 접점에서 얻는 정보를 통합해 인사이트 도출 속도를 높이는 용도로 활용되고 있음을 시사한다.
기술적 관점에서는 협업형 대규모 언어 모델(LLM) 기반 도구가 항공사 같은 복합적 운영 조직의 의사결정 주기에 직접 관여하는 사례로 해석될 수 있다. 다만 제공된 정보만 보면 구체적인 워크플로 변경, 성과 지표, 데이터 보안·프라이버시 처리 방식 등은 확인되지 않아 실제 적용 맥락과 효과를 판단하려면 원문 본문이나 추가 근거가 필요하다.
