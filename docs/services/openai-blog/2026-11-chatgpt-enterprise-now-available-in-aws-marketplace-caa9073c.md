# ChatGPT Enterprise now available in AWS Marketplace

> OpenAI Blog · 2026-11-09 · Product

---

피드 기준으로는 OpenAI가 2026-11-09에 **ChatGPT Enterprise**를 AWS Marketplace에서 제공한다고 알렸다. 제공된 설명은 해당 배포를 통해 조직이 **기존 AWS 구매·청구 관계를 이용해 조달을 단순화**할 수 있다고만 적고 있어, 실제 가격·라이선스 옵션·배포 방식 등 구체 조건은 메타데이터에서 확인되지 않는다.

이 공지는 AWS 계정을 통한 구매 및 청구 통합을 선호하는 조직에게 관련 구매 경로가 하나 더 열렸다는 사실을 전할 뿐이며, 제품의 기술적 기능이나 통합 사례, 계약 세부조건 등은 원문 전문 또는 판매 페이지를 통해 확인해야 한다.
