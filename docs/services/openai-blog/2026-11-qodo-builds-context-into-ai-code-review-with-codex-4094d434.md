# Qodo builds context into AI code review with Codex

> OpenAI Blog · 2026-11-02 · Startup

---

피드 메타데이터에 따르면 스타트업 Qodo가 OpenAI의 Codex에 회사 내부 지식과 코딩 규칙을 통합하는 기능을 발표했습니다. 메타데이터 요약은 이 통합을 통해 개발자가 풀 리퀘스트를 열기 전에 레포지토리 전반에서 **P0(심각) 이슈를 찾아낼 수 있도록 돕는다**고 설명합니다.

제공된 정보만 보면 변화의 핵심은 '사내 지식·코딩 표준을 Codex 기반 코드 리뷰 워크플로에 포함'시키는 점이며, OpenAI 블로그 메타데이터에는 2026-11-02 게시일이 표시되어 있습니다. 동작 방식, 성능 수치, 도입 절차 등 세부 내용은 메타데이터에 포함되어 있지 않아 본문에서 확인할 수 없습니다. 따라서 이 브리핑은 발표 사실과 기대되는 효과에 국한해 전하며, 구체적 기술·구성 정보는 원문 또는 공급사 자료를 추가 확인해야 합니다.
