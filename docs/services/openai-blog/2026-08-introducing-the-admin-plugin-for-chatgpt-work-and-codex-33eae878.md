# Introducing the Admin plugin for ChatGPT Work and Codex

> OpenAI Blog · 2026-08-25 · AI Adoption

---

피드 기준으로는 OpenAI가 ChatGPT Work와 Codex용 ‘Admin’ 플러그인을 도입해 워크스페이스 사용 분석, 구성원·권한 관리, 한도 조정, 관리자 요청 처리 등 운영·관리 기능을 제공한다고 요약되어 있다. 제목과 요약만 보면 조직 단위의 AI 도입 시 가시성 확보와 권한 통제 등 관리 측면을 보강하려는 의도로 풀이된다.
기술적 의미로는 사용량 분석과 권한 제어가 모델 배포·거버넌스 실무에 실질적 도움을 줄 수 있다는 점이 주목된다. 다만 제공된 메타데이터만으로는 구현 방식, 접근 제어의 상세, 로그·감사 처리나 API 통합 방식 등 기술적 세부가 확인되지 않으므로 구체적 영향과 적용 맥락은 원문과 기술 문서를 통해 검증할 필요가 있다.
