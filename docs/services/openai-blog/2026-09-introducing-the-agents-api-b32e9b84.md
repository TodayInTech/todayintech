# Introducing the Agents API

> OpenAI Blog · 2026-09-10 · Product

---

OpenAI가 발표한 'Agents API'는 피드 기준으로는 클라우드 에이전트를 구축·배포하기 위한 관리형 서비스로 소개됩니다. 메타데이터에 따르면 이 서비스는 Codex harness를 기반으로 에이전트 오케스트레이션, 장기 실행 세션 유지, 외부 도구 사용과 같은 기능을 지원하도록 설계되어 있어 개발자가 에이전트의 상태 관리와 도구 연동을 보다 쉽게 처리할 수 있게 돕는다는 취지로 보입니다.
제공된 정보만 보면 Agents API는 복잡한 워크플로를 가진 애플리케이션에서 에이전트 개발과 운영 부담을 줄일 잠재력이 있습니다. 다만 피드 수준의 설명에는 API 명세, 인증·보안 모델, 비용 구조나 지원 플랫폼 같은 구체적 기술·운영 세부사항이 없어 실제 도입 시에는 추가 문서와 검증이 필요하다는 점을 염두에 둬야 합니다.
