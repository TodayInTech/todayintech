# Shield helps technicians hand off legacy portal work with OpenAI

> OpenAI Blog · 2026-11-13 · Customer story

---

피드 기준으로는 Shield가 OpenAI 솔루션을 도입해 IT 현장 작업의 인계(hand-off)를 지원하고 있다고 전해집니다. 공개된 메타데이터에 따르면 **Shield는 OpenAI의 Forge 에이전트를 활용해 레거시 포털에서 수행하던 작업 흐름을 에이전트가 탐색하도록 하여**, IT 기술자들이 판단과 의사결정이 필요한 업무에 더 집중할 수 있게 한다고 설명되어 있습니다. 게시일은 2026-11-13이며 원문은 OpenAI 비즈니스 고객 사례 페이지에 게재되어 있습니다. 제공된 메타정보만 보면 적용 범위·기술적 구현 세부사항·성과 지표 등은 확인되지 않으므로, 구체적 도입 방법이나 성능 관련 내용은 원문 또는 추가 자료 확인이 필요합니다.
