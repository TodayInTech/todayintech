# Offering Zero Data Retention for frontier models

> OpenAI Blog · 2026-08-19 · Company

---

피드 기준으로는 OpenAI가 'frontier models'에 대해 적격 API 고객에게 데이터 무보존(Zero Data Retention) 정책을 재확인하고, 개인정보를 침해하지 않으면서 고급 안전성 처리를 가능하게 하는 'Private Safety Processing'이라는 접근을 예고한 것으로 전해집니다. 제공된 메타데이터는 이러한 정책 방향과 명칭을 요약하지만, 구체적인 기술 구현 방식이나 적용 대상·계약 조건 등은 밝히지 않습니다.
기술적 의미로는 고객 입력의 학습 데이터 유입을 막으면서도 모델 유해성·안전성 문제를 별도 방식으로 처리하려는 시도로 읽힐 수 있습니다. 다만 피드 정보만으로는 Private Safety Processing이 어떤 암호화·격리·연산 오프로드 기법을 쓰는지, 성능·지연·비용에 미치는 영향이나 규제 준수 측면의 세부 보완책은 확인되지 않습니다. 따라서 보안·개발·법무 담당자들은 원문과 후속 공지에서 공개되는 세부를 바탕으로 도입 타당성·계약 조항·운영 리스크를 재평가할 필요가 있습니다.
