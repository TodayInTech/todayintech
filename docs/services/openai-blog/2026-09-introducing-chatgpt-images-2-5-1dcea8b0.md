# Introducing ChatGPT Images 2.5

> OpenAI Blog · 2026-09-08 · Product

---

OpenAI가 'ChatGPT Images 2.5'를 발표했다. 피드 요약에 따르면 이번 버전은 사용자가 제시한 아이디어, 스케치, 참조 사진을 보다 개인화되고 정교한 이미지로 변환해 원래 의도를 더 잘 반영하도록 돕는 데 초점을 둔다. 제품 설명만으로는 스타일 조정과 디테일 보정, 레퍼런스 통합 등 여러 단계에서 이미지의 마무리 품질과 사용자 맞춤화가 향상된 것으로 읽힌다.
피드 기준으로는 이 업데이트가 이미지 생성 도구를 디자이너와 콘텐츠 제작자의 초기 시각화·반복 작업에 더 밀착시키려는 의도로 보인다. 사용자 입력(스케치·참조 사진)을 기반으로 한 ‘정교한 반영’은 프로토타이핑과 맞춤 제작 흐름에서 유용할 가능성이 있으나, 구체적 알고리즘 변경 사항이나 성능 지표, API 및 상용 적용 범위 등은 제공된 정보만 보면 확인되지 않아 세부 기능과 한계는 원문 전문을 통해 추가 확인이 필요하다.
