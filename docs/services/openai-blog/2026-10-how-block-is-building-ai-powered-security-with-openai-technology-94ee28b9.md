# How Block is building AI-powered security with OpenAI technology

> OpenAI Blog · 2026-10-14 · 보안/인공지능

---

블록(Block)이 오픈AI 기술을 활용해 AI 기반 보안 역량을 강화하고 있다는 간단한 소개입니다. 피드 기준으로는 블록의 보안팀이 위협 조사 속도를 끌어올리고 몇 분 내에 패치 제안을 마련할 수 있게 됐다는 점이 핵심으로 제시돼 있습니다. 원문에서 구체적 아키텍처나 사용된 모델, 통합 방식 등 세부는 제공되지 않았습니다.
이런 변화는 위협 탐지·조사 과정의 자동화와 대응 시간 단축, 반복 업무 경감이라는 보안 운영 측면의 잠재적 이익을 시사합니다. 다만 제공된 정보만으로는 검증 절차, 오탐·미탐율 같은 성능 지표나 실제 배포 환경에서의 거버넌스 적용 여부를 판단할 수 없으므로 추가 공개 자료가 있어야 실효성과 한계를 보다 정확히 평가할 수 있습니다.
