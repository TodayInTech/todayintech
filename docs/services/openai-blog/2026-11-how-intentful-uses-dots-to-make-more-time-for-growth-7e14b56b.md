# How Intentful uses dots to make more time for growth

> OpenAI Blog · 2026-11-24 · AI 도구/업무자동화 사례

---

Intentful의 창업자 Marina Petrova는 개인화된 에이전트(원문: dot) **Aria**를 도입해 제안서 작성과 리서치 작업을 며칠에서 몇 시간으로 단축했다고 밝혔다. Aria는 단순한 템플릿 자동화 수준을 넘어서, 스프레드시트·사이트맵 분석부터 CRM·메시징 연동, 제안서 초안 작성까지 연결된 워크플로를 수행했다.

## 스프레드시트·사이트맵 필터링과 가격 모델 자동화
원문에 따르면 Marina는 URL 목록과 포함 기준(예: 읽을 수 있는 사이트맵, 페이지 수 **최대 3,000**)을 Aria에 제공했다. Aria는 **약 300개** 사이트의 사이트맵을 검토해 어떤 사이트를 새 오퍼에 포함할지 선별했고, HubSpot 등 과거 영업 데이터를 ChatGPT 플러그인을 통해 확인해 이전 계약의 가격 정보를 추출했다. 그 결과 페이지 수에 따른 요금 티어를 기준으로 한 가격 모델을 함께 만들고, 이를 **한 페이지짜리 제안서 초안**으로 빠르게 정리했다.

## 툴 통합과 선제적 상태 감지
Aria는 Google Drive 템플릿을 알고 있어 제안서 레이아웃을 자동으로 맞추고, Gmail·Slack 플러그인을 통해 대화와 미해결 작업을 모니터링한다. 예컨대 사용자가 오프라인일 때 기다리던 회신을 찾고 "콜 초대"를 알리거나, 동료가 추가한 슬라이드를 감지해 연사 노트를 자동으로 업데이트했다. 또한 교육 자료 접근 요청을 스스로 처리하고, 녹화에 접근 불가한 소프트웨어 오류를 발견해 수정 제안을 했다는 사례도 포함된다.

## 권한 통제와 실무적 영향
Marina는 Aria가 접근할 수 있는 정보를 선택하며, 아웃바운드 이메일은 항상 사람이 최종 검토한다고 밝힘으로써 권한 통제와 검토 주체를 유지했다. 원문 근거로는 Aria가 과거 제안의 갱신일 불일치를 발견해 해당 날짜를 새 초안에서 제외한 사례 등 구체적 행동들이 제시되어 있다.

이 사례는 ChatGPT 플러그인 기반 에이전트가 스프레드시트·CRM·문서·메시지 도구를 결합해 실무 반복 작업을 대폭 줄일 수 있음을 보여준다. 본문은 Aria의 구체적 작업(사이트맵 수, 페이지 수 기준, 과거 계약 데이터 활용, Google Drive 템플릿 사용, Gmail/Slack/HubSpot/Asana 연동)만을 근거로 기술적·실무적 의미를 설명한다.
