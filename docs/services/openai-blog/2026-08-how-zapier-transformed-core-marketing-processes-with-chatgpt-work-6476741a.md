# How Zapier transformed core marketing processes with ChatGPT Work

> OpenAI Blog · 2026-08-10 · 엔터프라이즈 AI/마케팅 자동화

---

피드 기준으로는 OpenAI 블로그의 요약에서 Zapier의 엔터프라이즈 마케팅팀이 ChatGPT Work를 활용해 리드 퍼널의 이탈을 줄이고 캠페인 자산을 제작하며 리포팅을 자동화했다고 전합니다. 해당 게시물은 2026-08-10자로 표시되어 있으며, 요약 정보만으로도 기업 마케팅 팀이 LLM 기반 툴을 운영에 직접 적용한 사례임을 알 수 있습니다.
기술적 관점에서는 이 사례가 마케팅 워크플로에 LLM을 통합해 퍼널 최적화, 콘텐츠 생성, 보고 자동화 같은 반복적·규모적 업무를 보조하거나 자동화할 가능성을 시사합니다. 그러나 피드 메타데이터만으로는 통합 방법론, 자동화 범위, 구체적 성과 지표가 제공되지 않아 실제 적용 방식과 효과는 추가 확인이 필요합니다. 기술 독자는 이 사례를 실무 워크플로 자동화와 리포트 파이프라인 설계에 대한 참조점으로 검토하면 유용할 것입니다.
