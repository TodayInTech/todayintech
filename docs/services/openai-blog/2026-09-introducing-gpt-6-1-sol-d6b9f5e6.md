# Introducing GPT-6.1 Sol

> OpenAI Blog · 2026-09-29 · Product

---

피드 기준으로는 'GPT-6.1 Sol'이 코딩, 일반적인 컴퓨터 활용, 그리고 전문 업무용으로 'near-Astra' 수준의 지능을 목표로 하는 모델로 소개되며, 가격은 Astra의 표준 API 입력·출력 토큰 가격의 1/5 수준이라는 점이 핵심입니다. 공개 일자는 2026-09-29로 메타데이터에 표시되어 있고, 피드 요약은 성능 수준 비교와 가격 경쟁력이 이번 발표의 중심임을 알려줍니다.
제공된 정보만 보면 이 발표는 고성능 모델을 더 낮은 토큰 비용 구조로 제공해 비용 민감한 개발·제품 적용을 촉진하려는 시도로 해석됩니다. 다만 구체적인 성능 지표, API 호환성, 지연(latency)·스케일링 특성 등은 피드에 포함돼 있지 않아 실제 적용 이득과 한계는 추가 공개 자료나 벤치마크를 통해 확인해야 할 것으로 보입니다.
