# Kobo can run apps now

> Hacker News · 2026-08-21 · 오픈소스/임베디드

---

BandarLabs의 Cobalt는 Kobo 전자책기에서 자체 앱을 실행할 수 있게 해주는 오픈소스 애플리케이션 플랫폼이다. 한 번 USB로 설치하면 이후 앱은 기기 자체에서 Wi‑Fi로 설치·업데이트·제거되며, 각 앱은 스톡 하드웨어 위에서 자신의 권한에 제한된 별도(unprivileged) 프로세스로 동작한다. 배포 방식은 GitHub 릴리스에서 읽는 서명된 카탈로그와 각 패키지의 서명된 매니페스트·정적 ARM 바이너리로 구성돼 런타임이 카탈로그·패키지·설치된 매니페스트·바이너리 서명을 확인한 뒤 실행한다는 점이 핵심이다. 설치가 중단되더라도 기기가 이전 버전을 유지하도록 복구 안전성을 생각한 점과 플랫폼 자체의 업데이트는 앱 카탈로그와 별개 채널로 동작한다는 점도 기술적으로 의미가 있다.
개발자 경험은 Rust SDK 중심으로 설계돼 있어 KoboApp 트레이트를 구현하고 선언적으로 화면을 기술하면 런타임이 레이아웃, 전자잉크 리프레시, 뒤로가기·라이프사이클을 처리한다. 네트워크·스토리지·오디오·전면조명·Wi‑Fi 같은 자원은 capability‑gated로 앱이 자원을 직접 열람하지 않고 권한 요청을 통해 거부 값을 처리할 수 있게 설계됐다. 현재 하드웨어 검증은 Clara BW 프로파일만 테스트된 상태이며, 부트 체인은 교체하지 않고 정확한 하드웨어·펌웨어 매치에서만 기기 쓰기를 허용한다고 명시해 안전 경계도 제시한다. 포팅이나 앱 기여는 풀리퀘스트 기반으로 이루어지고, 첫 설치 이후 재부팅으로 스톡 리더로 돌아갈 수 있다는 점 때문에 커스텀 앱을 안전하게 시험해볼 수 있는 플랫폼으로 읽힌다.
