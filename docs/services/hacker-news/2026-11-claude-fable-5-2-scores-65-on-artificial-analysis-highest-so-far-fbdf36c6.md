# Claude Fable 5.2 scores 65 on Artificial Analysis, highest so far

> Hacker News · 2026-11-09 · AI 모델 출시/평가

---

**Anthropic의 Claude Fable 5.2(2026-11-09)**가 Artificial Analysis의 Intelligence Index에서 **65점**을 기록했다. 이 수치는 같은 가격대 모델의 중앙값(40)을 크게 웃도는 결과다. 근거 자료는 모델이 추론(reasoning) 버전이며 텍스트·이미지 입력을 받고 텍스트를 출력한다고 명시한다.

## 성능과 비용·지연의 핵심 수치
- Intelligence Index 점수: **65** (비교 중앙값 40)
- 평가 중 생성한 출력 토큰: **275M** (중간값 72.8M 대비 매우 장문)
- 작업당 평균 소요 시간: **46.4분** (동급 중앙값 12.7분)
- 첫 응답 토큰까지 시간: **215.95초** (중앙값 11.78초)
- 가격(Anthropic API 기준): **$8.00 / 1M 입력 토큰**, **$40.00 / 1M 출력 토큰**
- 평가 기준 평균 비용: **$26.54 / 작업**; 블렌드 환산 시 **$5.74 / 1M 토큰**(7:2:1 캐시/입력/출력 비율 가정)

위 수치는 원문 근거의 수치들을 그대로 인용한 것이다. 자료는 이 버전이 '추론 모델'이며 체인-오브-소트(extended thinking)를 사용해 복잡한 문제를 단계적으로 풀어낸다고 명시한다.

## 기술적 의미와 실무적 시사점
Claude Fable 5.2의 높은 Intelligence Index 점수는 복합 지식 작업, 코딩, 과학적 문제 해결 등에서 품질이 우수할 가능성을 시사한다. 동시에 **매우 큰 출력 토큰량(275M)**과 **긴 처리 시간(46.4분/작업)**은 두 가지 원인과 연결된다고 볼 수 있다: 추론(extended thinking) 모드가 내부적으로 긴 체인-오브-소트 과정을 생성하고, 모델이 일반적으로 상세·장문 응답을 산출한다는 점이다. 이 조합은 출력 토큰 비용과 API 응답 지연을 크게 증가시킨다.

1M 토큰 컨텍스트(약 1500장 분량)를 지원하는 점은 장문 문서 분석, 대화 이력 전체를 반영한 복합 질의응답, 멀티모달 문서(텍스트+이미지) 분석 등에서 강점이 된다. 하지만 근거에 따르면 모델은 **프로프라이어터리(비공개 가중치)**로, 파라미터 수 역시 공개되지 않아 로컬 호스팅이나 자체 미세조정은 불가능하다.

## 실무 결정을 위한 고려사항(근거 기반)
- 고품질의 심층 분석이나 긴 맥락을 필요로 하는 연구·리포트 자동화 등에서 가치를 기대할 수 있다. 높은 지연과 출력 토큰 비용을 감내할 수 있는 배치(비실시간) 워크로드가 적합하다.
- 실시간 인터랙티브 서비스(챗봇, 짧은 응답 중심)나 대량 트랜잭션 처리에는 비용·지연 때문에 부적합할 가능성이 높다.
- 출력이 매우 장문이므로 토큰 요금 구조($40/1M 출력)가 비용을 빠르게 키운다. 출력 길이를 통제하거나 요약 후 검토하는 워크플로우가 비용 관리에 필수적이다.
- 평가와 일부 성능·가격 수치는 Anthropic의 API를 기준으로 보고되었고, 제공자에 따라 가격은 변동될 수 있다.

근거는 공개된 평가 페이지의 수치와 FAQ에 한정된다. 모델의 내부 구조(파라미터 수 등)와 운영·정책 세부사항은 근거에 포함되지 않아 그 부분은 다루지 않았다.
