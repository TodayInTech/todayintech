# Claude: System Prompts

> Hacker News · 2026-08-16 · AI/Platform

---

클로드(Claude)의 웹 인터페이스와 모바일 앱은 대화 시작 시 시스템 프롬프트를 사용해 최신 정보(예: 현재 날짜)를 모델에 전달하고, 응답 형식에 영향을 주는 행동 권고(예: 코드 스니펫을 항상 마크다운으로 제공)를 적용한다고 제공합니다. 이 시스템 프롬프트는 정기적으로 업데이트되어 클로드의 응답 개선에 활용되며, 릴리스 노트에서는 모델별로 여러 날짜 항목이 있을 때 버전 간 변경점을 굵은 글씨로 표시해 구분한다고 명시되어 있습니다. 다만 이 업데이트들은 클로드 API에는 적용되지 않는다고 분명히 밝혀 API를 통해 모델을 사용하는 환경과 웹/앱 사용자의 경험이 다를 수 있음을 알려줍니다.
기술적 의미는 운영·개발 관점에서 분명합니다. 웹·모바일 환경에서는 시스템 프롬프트를 통한 최신 정보 주입과 스타일·형식 강제가 서비스 전반의 일관성에 기여하지만, API 소비자는 이러한 UI 레벨의 프롬프트 변경 영향을 받지 않으므로 애플리케이션 수준에서 별도의 프롬프트 관리가 필요합니다. 또한 자료에 따르면 Claude 4.6 세대부터는 각 모델 ID가 고정된 스냅샷으로 관리되어 해당 모델은 단일 항목만 가지므로 재현성과 버전 추적이 더 명확해지는 반면, 원문 근거만으로는 업데이트의 정확한 빈도나 구체적 내용 범위 등 세부 운영 정책은 확인할 수 없습니다.
