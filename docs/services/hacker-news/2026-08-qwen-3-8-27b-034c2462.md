# Qwen 3.8 27B

> Hacker News · 2026-08-14 · 모델 릴리스/배포

---

Qwen3.8-27B의 FP8 양자화 가중치와 설정 파일이 Hugging Face Transformers 형식으로 공개되었으며, vLLM·SGLang·TokenSpeed 등 주요 추론 프레임워크와 호환된다고 안내합니다. 양자화는 블록 크기 128의 세밀한 FP8 방식으로 수행되었고, 성능은 원모델과 거의 동일하다고 명시돼 배포 가능성이 높습니다. 모델은 Qwen3.5의 구조적 기반을 계승하면서 코드 작성, 전문 업무, 연구, 장기 에이전트 작업에서 성능 향상을 내세우며, 이미지·영상 이해를 네이티브로 지원하는 비전-언어 역량과 MTP(다중토큰 예측) 등 훈련 특성이 포함되어 있습니다. 아키텍처·사양도 공개되어 있는데 27B 파라미터, 64개 레이어, 은닉 차원 5120, 토큰 임베딩 248,320(패딩), 기본 컨텍스트 길이 262,144 토큰(최대 1,000,000토큰 확장 가능) 등이 확인됩니다.
실무 통합 관점에서 OpenAI Python SDK 형태의 채팅 완성 예시와 멀티미디어 입력(이미지·비디오) 처리 예제가 포함되어 있어 바로 테스트해볼 수 있습니다. Qwen3.8은 기본적으로 '생각하기(thinking)' 모드가 켜진 채 응답하며, reasoning_effort(예: xhigh/medium/low)와 preserve_thinking 옵션으로 추론 깊이와 역사적 추론 블록 보존을 조절할 수 있습니다. 권장 샘플링 파라미터(생각 모드와 비생각 모드별)와, 1M 컨텍스트 환경에서 내부 추론과 최종 응답에 할당할 토큰(예: 추론 262,144 / 최종 응답 131,072)도 제시되어 에이전트형 워크플로우나 장기 추론 적용 시 실무적 지침으로 활용하기 좋습니다. 또한 호스팅 형태의 Qwen Cloud 서비스로 더 많은 프로덕션 기능(기본 1M 컨텍스트 등)이 제공될 예정이라고 덧붙여 배포·운영 옵션까지 고려할 수 있습니다.
