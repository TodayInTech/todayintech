# Delta

> Hacker News · 2026-08-12 · developer tools

---

Zed 팀이 공개한 Delta는 에이전트와 사람이 동일한 문맥에서 함께 코드를 작성하고 검토할 수 있게 설계된 멀티플레이어 협업 환경입니다. 핵심은 DeltaDB로, 대화와 워크트리를 실시간으로 복제해 모든 편집과 대화가 커밋 사이에 기록되도록 합니다. 기존 Git 리포지토리와 연동되므로 평소처럼 커밋하고 푸시하는 흐름을 유지하면서도 스레드 안에서는 코드의 특정 라인·diff·계획·대화 블록에 주석을 달고 그 주석이 코드 변화에 따라 계속해서 올바른 자리와 맥락을 유지하도록 합니다. 에이전트는 스레드 내부에서 같은 대화와 결정을 공유하며, 잘못된 점이 보이면 의도를 다시 추적할 필요 없이 에이전트에게 설명이나 수정을 요청할 수 있습니다.
Delta는 기술적 제약으로 기존 Zed에 기능을 붙이는 대신 새로운 애플리케이션으로 시작했습니다. 각 참여자는 로컬에 동기화된 코드 복사본을 가지며, 클라우드 러너로 작업을 옮기면 노트북을 닫아도 에이전트와 대화·코드가 계속 동기화됩니다. 브라우저 접근을 위해 Rust로 만든 네이티브 애플리케이션을 WebAssembly와 WebGL로 컴파일해 동일한 사용자 경험을 제공하려는 점, Claude Code를 시작으로 서드파티 에이전트 하니스와 연동하는 점, 그리고 에이전트가 만들어내는 방대한 출력도 전체 diff와 전사를 숨기지 않고 빠르게 렌더링하도록 설계한 점은 코드 리뷰와 에이전트 통합이 실무에서 당면한 문제들을 직접 해결하려는 의도로 읽힙니다. 현재는 프라이빗 베타 초대가 배포 중이며, 더 많은 사용자를 순차 초대할 예정이라고 합니다.
