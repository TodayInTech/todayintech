# Docker Agent

> Hacker News · 2026-10-07 · 개발자 도구 (AI 에이전트)

---

docker-agent는 선언적 YAML 구성으로 AI 에이전트를 정의하고 실행·공유할 수 있도록 설계된 Docker CLI 플러그인입니다. 소스 근거에 따르면 사용자는 코드 작성 없이 agents 블록에 모델과 도구셋을 적어 에이전트를 만들고, docker agent run으로 실행하거나 docker agent new로 인터랙티브하게 생성할 수 있습니다. 멀티에이전트 아키텍처를 통해 역할을 분담하는 팀을 구성하고 자동으로 작업을 위임할 수 있으며, 예시 YAML에는 openai/gpt-5-mini 같은 모델 지정이 포함되어 있습니다. 또한 로컬·원격 또는 Docker 기반 MCP 서버와의 통합, 내장된 think/todo/memory 도구와 RAG( BM25, 임베딩, 하이브리드 검색, 재순위화) 플러그인 지원 등 풍부한 도구 생태계를 강조합니다.
기술적으로 눈여겨볼 점은 공급자 비종속성(provider-agnostic)입니다. 설명에 명시된 지원 목록에는 OpenAI, Anthropic, Gemini, AWS Bedrock, Mistral, xAI, Docker Model Runner 등이 있어 클라우드 API와 로컬 모델을 쉽게 교체·시험해볼 수 있습니다. 에이전트를 OCI 레지스트리에 패키지해 배포하거나 어디서나 끌어와 실행하는 워크플로우는 재현성과 배포 편의성을 높입니다. 설치는 Docker Desktop(4.63+)에 플러그인이 기본 포함되거나 Homebrew 및 바이너리 릴리스로 가능하고, 로컬 모델을 쓰려면 Docker Model Runner를 선택하거나 API 키를 설정하도록 안내합니다. 원문은 또한 익명 사용 데이터 수집(telemetry)을 밝히고 있어 실제 운영 환경 도입 시 고려할 보안·프라이버시 요소가 존재함을 알 수 있습니다.
