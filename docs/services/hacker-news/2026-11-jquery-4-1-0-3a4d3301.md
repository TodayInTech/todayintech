# jQuery 4.1.0

> Hacker News · 2026-11-17 · JavaScript / Web

---

**jQuery 4.1.0**이 배포되었으며, AJAX API 확장·선택자 관련 보안 수정·코어 내부 변경 등 실무에서 눈여겨볼 만한 변경을 포함합니다. 주요 변경은 릴리스 노트(커밋·이슈 참조)에 명시되어 있습니다.

## AJAX: jqXHR.responseURL과 전송 콜백 대체 API

AJAX 영역에서 **jqXHR에 responseURL 필드가 추가**되었습니다 (#4339, 5691e03a). 이 필드는 응답의 최종 URL을 jqXHR 객체에서 직접 확인할 수 있게 해, 리다이렉션이나 프록시 뒤의 실제 응답 위치를 파악할 때 유용합니다. 또한 전송(transports)을 위한 **대체 completeCallback API**가 추가되었습니다 (a05c3d73). 릴리스 노트는 기능 추가를 명시하고 있으므로, AJAX 요청 후 응답 URL에 의존하는 로직이나 커스텀 전송 구현이 있는 프로젝트는 변경 사항을 확인해야 합니다.

## 선택자 관련: 정규식·ReDoS·유니크 정렬 개선

선택자 모듈에서 여러 버그와 보안 문제가 처리되었습니다. 구체적으로 **식별자 매칭의 ReDoS(정규식 기반 서비스 거부) 취약점이 수정**되었습니다 (d41cf7dd). 또한 Safari 27의 정규식 인터프리터 버그에 대한 우회(b557a8c4), runescape 정규식 수정(e77f87c8), 잘못된 이스케이프 코드 포인트를 U+FFFD로 디코드하는 처리(#5845, 7e1efd77)가 포함됩니다. 중복 제거 알고리즘(jQuery.uniqueSort)도 최적화(35789e76)되었습니다. 보안 패치가 포함된 만큼 선택자 관련 사용자 입력을 처리하는 코드가 있는 경우 우선적으로 테스트해야 합니다.

## DOM 접근·코어 루프·XML 지원

코어 쪽에서는 루프를 재구성해 배열 경계 접근을 피하도록 변경(5f8ed054)이 이루어졌고, 기존의 getElementsByTagName/ getElementsByClassName 호출을 **querySelectorAll로 대체**하는 결정이 포함되어 있습니다 (#3642, 53a2bcf9). 또한 XML 문서를 지원하기 위해 createElementNS 사용이 도입되었습니다 (#4730, dcb31ae8). querySelectorAll 기반 전환은 구현 세부와 브라우저별 동작 차이에서 성능·동작 변화가 발생할 수 있으므로, DOM 집약적 코드를 가진 코드베이스는 회귀 테스트가 권장됩니다.

## 경량화·문서·테스트

데이터 모듈에서 바이트 절감 작업(eb9acfe9), 문서에서는 상업 지원 공급업체 추가(TuxCare, b75c1fef), README의 XMLHttpRequest 표기 수정(#5903, 71c0dd14), 기계 생성 기여를 위한 가이드라인(51eb576c) 등이 포함되어 있습니다. 테스트 스위트도 여러 케이스를 보강하거나 완화해 브라우저별 차이를 반영하도록 업데이트되었습니다.

## 실무적 영향

- 보안: 선택자 매칭의 ReDoS 수정은 잠재적 취약점을 제거하므로 즉시 적용 가치가 큽니다. (커밋 d41cf7dd 참조)
- AJAX 코드: responseURL의 추가로 리다이렉트 후의 실제 응답 위치를 읽는 로직이 단순해질 수 있습니다.새 필드 활용을 검토하세요.
- 호환성/성능: getElementsBy* → querySelectorAll 전환과 내부 루프 변경은 성능 특성에 영향을 줄 수 있으므로 DOM 집약적 모듈은 회귀 테스트를 권장합니다.

원문 릴리스 노트에는 각 변경에 대한 커밋/이슈 참조가 포함되어 있으니, 구체적 커밋을 확인해 필요한 테스트 범위와 코드 변경 여부를 결정하시기 바랍니다. 근거: 배포 노트(릴리스 텍스트, commit/issue 식별자 포함) (chunk-0001).
