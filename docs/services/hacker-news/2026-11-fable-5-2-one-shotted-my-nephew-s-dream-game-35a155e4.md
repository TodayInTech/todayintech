# Fable 5.2 one-shotted my nephew's dream game

> Hacker News · 2026-11-09 · AI · 게임 개발

---

**Fable 5.2가 아이의 꿈 게임을 한 번에 완성했다**

작성자는 자신의 조카가 그린 캐릭터와 보스 드로잉을 입력해, **Claude Fable 5.2**에 '한 번에 끝내라'는 프롬프트를 주자 수 시간~수일 내에 플레이 가능한 횡스크롤 비트엠업을 얻었다고 보고한다. 초기에는 Claude Code + Opus 4.8 + Fable 5로 만든 시제품을 2026년 6월에 내놨지만, 이후 Fable 5.2를 쓰자 대대적인 재작성과 자산 생성이 이뤄졌다(작성자 설명).

## 무엇을 만들었나 — 산출물과 수치

작성자에 따르면 Fable 5.2는 기존 코드를 대부분 교체해 게임을 새로 만들었고, 개발 과정에서 생성된 자산은 이미지·오디오·게임플레이 검사까지 포함한다. 글에 명시된 산출물·활동은 다음과 같다(글쓴이 보고 기준):

- **최종 게임**: 12스테이지, 18선택 가능한 영웅(원래 5→18로 확대), 12 보스, 4인용 컨트롤러 지원
- 이미지·오디오 생성: 본문에는 한 시점에서 **약 175장의 이미지와 140개의 오디오 클립**이 생성되었다고 쓰였고, 최종 토큰 집계에서는 **OpenAI 이미지 약 500장(스프라이트시트·컨셉·배경 등)**로 기록됨
- 오디오: ElevenLabs로 만든 **11곡, 약 100개의 효과음, 90개의 아나운서 대사**
- 요청·토큰: 약 **600회 요청(2일)**, 캐시에서 읽은 토큰 약 **320M**, 캐시에 기록된 토큰 19M, 출력 토큰 1M — 저자는 이를 합쳐 대략 **340M 토큰**이 사용됐다고 보고함
- 자동검증: 에이전트가 플레이 봇을 만들어 **헤드리스 브라우저**에서 전체 12스테이지를 돌려 스크린샷을 검사하며 문제를 찾아 수정함

## 어떻게 동작했나 — 입력·외부 도구·검증

작성자가 제시한 프롬프트는 매우 권한을 부여하는(gassed-up) 형식으로, 외부 이미지·음성 API 사용 키 경로를 지시하고(예: ChatGPT Images 2.5, ElevenLabs), 기존 스캔 디렉터리의 자산을 활용하라 요청했다. 중요한 자동화 단계는 에이전트가 자체 플레이봇을 작성해 게임을 실행하고 스크린샷을 검사한 점이다. 또한 플레이 중에 발견된 디자인 변경(특정 캐릭터의 특수기 추가 등)을 프롬프트로 반영해 실시간으로 조정했다.

## 기술적·실무적 의미

글쓴이는 이번 사례를 통해 Claude Code + Fable 5.2 조합이 단일 워크플로우로 '완결된' 소규모 상업적 수준의 게임 프로토타입을 생성할 수 있음을 보여준다고 주장한다. 출처 근거만으로 해석하면, 핵심 변화는 **이미지·오디오 생성, 코드 재작성, 자동 플레이테스트를 한 에이전트 흐름으로 통합**한 점이다. 이는 초기 프로토타이핑과 빠른 반복에서 개발자가 수동으로 해야 했던 작업 일부를 에이전트가 대체할 수 있음을 시사한다.

다만 글쓴이는 Opus 5.5로 시험해보지 않았다고 명시하고 있으며, 일부 수치(이미지 개수 175 vs 500 등)는 본문 내 서로 다른 문단에서 다르게 보고되어 있어 정확한 최종 산출물 수치는 글쓴이의 집계 방식에 따라 달라질 수 있다. 또한 작성자는 상용 배포·저작권·외부 자산 사용 허가 등 절차를 논의하지 않고 단기간의 가정환경 실사용 사례만을 보고하고 있다.
