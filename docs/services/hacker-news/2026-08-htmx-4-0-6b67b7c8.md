# Htmx 4.0

> Hacker News · 2026-08-28 · 웹 개발

---

htmx 팀이 8개월의 작업 끝에 htmx 4.0.0을 공개했습니다. 내부 구현을 기존 XMLHttpRequest에서 fetch()로 옮긴 것이 출발점이었고, 이 변경을 통해 스트리밍과 확장성 측면에서 여러 구조적 개선이 가능해졌습니다. 사용자 관점에서 가장 큰 변화는 속성 상속이 암묵적(기본)에서 명시적(:inherited 접미사 필요)으로 바뀐 점으로, 부모에 쓴 hx-* 속성이 자식에 자동 적용되지 않아 마이그레이션 부담이 가장 큽니다. 이벤트 체계도 htmx:phase:action[:sub-action] 형태로 정리돼 기존에 듣던 이벤트 이름을 바꿔야 할 수도 있고, 히스토리 복원은 기본적으로 localStorage 캐시 대신 페이지 재요청 방식으로 바뀌어 서드파티 라이브러리와의 충돌 가능성을 줄였습니다. 내부적으로는 대다수의 변화가 사용자에게 투명하도록 설계되었으며, npm에서는 2.x를 당분간 latest로 유지해 비버전 CDN 사용자를 강제로 업그레이드하지 않도록 했습니다.
기능 측면에서는 두 가지 큰 추가가 눈에 띕니다. 모핑 스왑(아이디오모프 계열 알고리즘 통합)과 태그로 단일 요소 교체 이상의 복합 업데이트를 명확하게 표현할 수 있게 되었고, fetch 기반 확장 모델 덕분에 hx-preload, hx-download, hx-alpine-compat, hx-history-cache 등 다양한 확장과 hx-sse/hx-ws/hx-multipart 같은 스트리밍 확장들이 정교해졌습니다. 또한 hx-live라는 소규모 프론트엔드 스크립팅 솔루션과 htmax.js 번들로 확장 선택을 단순화했고, 마이그레이션을 돕는 CLI 검사기와 LLM용 스킬 파일도 제공해 전환 작업을 지원합니다. 종합하면 이번 릴리스는 장기 유지보수성과 외부 통합 안정성을 우선한 설계 전환이며, 이벤트명·상속·히스토리 동작 등 호환성 점검이 필요한 개발자에게 실무적 의미가 큽니다.
