# AI is a tool and using it well takes skill

> Hacker News · 2026-10-12 · AI/Opinion

---

Rich Hickey가 "'AI'는 도구가 아니다"라고 주장한 것에 대해 저자는 부분적으로 동의하면서도 결론에는 반대한다. 도구를 단순히 예측 가능성이나 단일 동작성으로만 규정할 수는 없으며, 톱이나 끌도 잘못 쓰면 해를 끼치듯 LLM 역시 조작자(웰더)의 판단과 숙련도에 따라 성능이 달라진다고 주장한다. LLM의 불확실성은 분명한 한계지만, 예측성·신뢰성·단순성 같은 속성이 도구를 정의하는 유일한 기준은 아니며 통제하기 어렵다고 해서 도구가 아니라 할 수는 없다는 점을 강조한다.
또한 자동화와 도구의 구분은 엄밀하지 않다고 지적한다. 컴파일러나 스프레드시트처럼 자동으로 많은 작업을 수행하는 시스템도 사람이 입력을 지정하고 결과를 검토하며 다음 행동을 결정하는 방식으로 '행사(wielding)'된다는 점을 들어 LLM을 동일한 범주로 볼 근거를 제시한다. 프로그래머가 LLM에 코드 설명을 요청하고 검증·테스트·요청 수정을 반복하는 피드백 루프는 의도·피드백·전문성이 존재함을 보여 주며, 오히려 LLM을 잘 쓰려면 무엇을 물어야 하고 언제 결과가 틀렸는지 판단할 줄 아는 기술이 필요하다고 설명한다. 마지막으로 "탈주"나 "음모" 같은 의인화된 표현은 공학적 문제를 감추는 프레임을 제공할 위험이 있으니 신중한 용어 사용을 촉구하며, 실질적인 구분은 기술을 숙련 있게 다루는지 아니면 이해·감독 없이 일괄 위임하는지에 있다고 정리한다.
