# Ghostty 1.4

> Hacker News · 2026-10-27 · Release

---

Ghostty 1.4.0이 2026년 10월 27일 공개됐다. 이번 메이저 릴리스는 **Kitty 그래픽스의 완전 구현(애니메이션·상대 배치 포함, 최초의 비-Kitty 터미널)**과 함께 대규모 성능·메모리 개선, 보안 권고, SSH·클립보드·렌더러 개선을 한데 묶는다. 릴리스는 172명 기여자, 2,889 커밋에 걸친 7개월 작업 결과물이다.

## Kitty 그래픽스: 애니메이션과 상대 배치

이제 kitten icat 등으로 전송된 애니메이션 이미지가 Ghostty에서 재생된다. 프레임 전송·합성·재생 제어를 지원하며, 터미널이 보이지 않을 때 애니메이션은 일시정지한다. 또한 한 이미지를 다른 이미지에 상대적으로 배치하는 상대 배치(relative placements)를 지원해 부모 이미지 이동에 따라 자식 이미지가 함께 움직인다. 릴리스 노트는 이 구현이 Kitty 프로토콜의 남은 주요 기능을 채웠다고 명시한다.

## 보안 권고(여러 GHSA 항목)

여러 보안 권고가 공개되었다(GHSA-4hwh-wx3w-3fqg, GHSA-mhff-mv4q-fp63, GHSA-hcr9-7hcr-mjm8 등). 주요 내용으로는 붙여넣기 보호가 캐리지 리턴을 줄바꿈으로 처리하지 않아 복사·붙여넣기로 명령이 실행될 수 있는 문제, 악성 Kitty 그래픽스 명령으로 크래시·거대한 할당·제한적 파일 읽기·삭제 가능성, tmux 제어 모드 출력으로 모든 창이 닫히는 크래시 등이다. 일부 취약점은 단순한 출력만으로 트리거되며, macOS에서는 cmd‑click/드래그로 로컬 파일·커스텀 URL 스킴이 실행될 수 있는 문제도 보고됐다. 저자는 GitHub에 CVE 배정을 요청했으나 아직 할당되지 않았다고 밝혔다.

## 렌더러·클립보드·SSH 통합

새 렌더 표면은 시스템 EGL 라이브러리를 요구하고, DMABUF를 내보내지 못하는 GPU 드라이버에서는 CPU 복사로 폴백한다(느림). Ghostty는 **Kitty 클립보드 프로토콜(OSC 5522)**을 macOS와 GTK에서 구현했다. OSC 52보다 확장된 형식(이미지·HTML 등)을 읽고 쓸 수 있으며, 기본 구성은 읽기 시 권한 프롬프트, 쓰기는 허용이고 단일 쓰기 크기 제한 기본값은 **64 MiB**다. 

SSH 통합은 새 CLI 동작인 **ghostty +ssh**로 정리됐다. 원격에 terminfo를 설치하고 COLORTERM·TERM_PROGRAM·TERM_PROGRAM_VERSION을 전달하며, terminfo 설치 실패 시 TERM=xterm-256color로 폴백한다. 기존의 ssh-env/ssh-terminfo 통합은 +ssh를 호출하도록 통일되었다.

## macOS·GTK와 libghostty

macOS 27(Golden Gate) 지원과 하위 호환성(최대 macOS 13까지)을 유지하며 여러 시각적·안정성 버그를 수정했다. GTK 측면에서는 분할(split) 드래그·드롭(마우스)을 macOS와 동등하게 지원하고, fractional scale에서 선명한 렌더링·EGL 기반 DMABUF 전달로 메인 스레드의 OpenGL 작업을 제거했다. 프로젝트는 GUI용 Windows 로드맵을 삭제했고, libghostty는 계속 개발되어 다른 프로젝트에서 사용될 것을 권장한다.

소스는 Ghostty 1.4.0 릴리스 노트이며(릴리스 노트에 명시된 GHSA ID와 구성 옵션 등 원문 문자열을 사용), 보안 권고의 CVE 배정은 아직 대기 중이라고 릴리스 노트가 밝힌 점을 전제로 작성했다.
