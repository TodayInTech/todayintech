# All AI-generated code should be Open Source

> Hacker News · 2026-11-15 · 오픈소스·라이선스

---

**모든 AI 생성 코드는 오픈소스여야 한다**고 주장하는 글이다. 저자는 AI 모델이 RMS의 GNU 프로젝트 이후 공개된 오픈소스 코드와 Stack Overflow·Stack Exchange 같은 CC 라이선스 자료를 대규모로 스크랩해 학습했다고 지적하며, 이를 바탕으로 생성된 코드를 폐쇄형·독점적으로 사용하는 것은 일종의 ‘라이선스 세탁’이라고 본다.

## 학습 데이터와 라이선스 문제
저자는 모델 학습에 쓰인 자료가 공개 소스와 크리에이티브 커먼즈 기반의 Q&amp;A 내용을 포함한다고 지적한다. 특히 Stack Overflow 등은 저작권상 출처 표기를 요구하는 라이선스 조항이 있어, 그 자료로 학습된 결과물을 그대로 독점화하는 것은 라이선스 의무를 회피하는 행위로 볼 수 있다는 것이 그의 주된 논점이다.

## 저작권적 근거와 관할권 차이
글은 비인간 저작물은 저작권을 가질 수 없다는 '원숭이 셀피' 판례 계열의 논리를 인용하고, 미국 저작권청이 AI 관련 판례를 참고한 점을 언급한다. 또한 Wikimedia Commons가 순수 AI 생성 이미지를 퍼블릭 도메인으로 분류하도록 요구한다는 사례를 들며, 반대로 영국처럼 컴퓨터 생성 저작물에 제한적 저작권을 인정하는 관할구역도 있어 법적 지형은 일관되지 않다고 썼다.

## 권고와 실무적 함의
저자는 이 논리에서 나아가 **개발자와 기업은 AI가 생성한 코드를 명시적으로 오픈소스 라이선스에 따라 공개하거나 CC0로 공용(퍼블릭 도메인)으로 헌납해야 한다**고 권한다. 또한 사람이 거의 검토·수정하지 않고 프롬프트만으로 생성된 코드는 특히 공개해야 한다는 점을 강조한다.

사실관계(학습 데이터 포함, 판례·Wikimedia 정책 인용)와 해석(오픈소스 공개 의무화 권고)은 원문 근거에서 직접 제시된 내용이다. 이 주장은 개발·배포 관행과 라이선스 준수, 저작권 논쟁을 촉발할 수 있어 실무적 파장이 있을 수 있으나, 법적 효력이나 구체적 시행 방안에 대해서는 원문에 구체적 지침이 없음을 함께 고려해야 한다.
