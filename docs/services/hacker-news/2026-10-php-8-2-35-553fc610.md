# PHP 8.2.35

> Hacker News · 2026-10-21 · Security

---

PHP 개발팀이 PHP 8.2.35를 긴급 배포했다. 이번 릴리스는 인증 없이 원격에서 코드 실행이 가능한 두 건의 치명적 취약점(CVE-2026-109618, CVE-2026-109619)을 수정하며, 모든 PHP 8.2 사용자는 즉시 업데이트하라는 권고를 받고 있다. 배포 쪽에서는 소스 다운로드와 Windows용 소스·바이너리를 다운로드 페이지에서 제공하고 변경 내역은 ChangeLog에 기록되어 있다고 명시되어 있다.
특히 완전한 완화책이 없어 '업데이트만이 유일한 안전한 선택'이라는 점을 분명히 하고 있어 운영 환경에서는 빠른 패치 적용과 배포 계획이 필요하다. 더불어 PHP 8.2는 2026년 12월 31일부로 공식적인 지원(보안 패치)을 종료하므로, 장기적으로는 지원되는 상위 버전으로의 이전 일정을 수립해야 한다. 인증 없는 원격 코드 실행은 시스템 완전 탈취로 이어질 수 있어 보안 관점에서 우선순위가 높고, 운영자와 패키지/배포관리자는 즉시 업데이트와 향후 마이그레이션 계획을 병행할 필요가 있다.
