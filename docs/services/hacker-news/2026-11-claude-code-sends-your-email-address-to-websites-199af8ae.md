# Claude Code sends your email address to websites

> Hacker News · 2026-11-05 · privacy

---

피드 기준으로는 Anthropic 관련 저장소에 올라온 GitHub 이슈 제목이 **"Claude Code sends your email address to websites"**이며, 해당 링크가 Hacker News에서 활발히 논의되고 있습니다(포인트 507, 댓글 172). 원문 링크는 GitHub 이슈 페이지(https://github.com/anthropics/claude-code/issues/107757)로 표기돼 있고, HN 토론 링크는 https://news.ycombinator.com/item?id=50385272로 제공됩니다.

제공된 메타데이터만 보면 이슈가 개인정보 전송 관련 우려를 제기한 것으로 보이나, 피드 기준으로는 이 주장의 근거나 기술적 세부사항은 확인되지 않습니다. 따라서 자세한 증거, 재현 방법, 개발사 입장 등은 원문 GitHub 이슈와 HN 토론을 직접 확인해야 합니다. 이 보도는 메타데이터로 확인되는 사실만을 바탕으로 작성되었습니다.
