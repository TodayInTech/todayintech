# Claude Code's "Don't Ask Again" exposes passwords in 1,122 public GitHub files

> Hacker News · 2026-11-07 · 보안/개발 도구

---

피드 메타데이터에 따르면 Claude Code의 기능인 "Don't Ask Again"이 공개 GitHub 파일 1,122건에서 비밀번호를 노출했다는 내용의 글이 2026-11-07 게시됐습니다. 출처는 Apiiro 블로그(링크 제공)이며 저자는 shmulc로 표기되어 있습니다. 이 보도는 Hacker News에서 146포인트, 댓글 104개로 높은 주목을 받았습니다. 

피드 기준으로 확인되는 사실만 기술하면 위 세 가지가 근거로 남습니다. 원문 본문 내용이나 노출 원인·영향 범위·수정 조치 등 세부 사항은 제공된 메타데이터에 포함되어 있지 않으므로 추가 확인이 필요합니다. 보안 팀이나 개발자는 원문과 관련 저장소를 직접 검토해 영향을 평가하는 것이 권장됩니다.
