# Google Has Removed MV2 Extensions from the Chrome Web Store, Including UBO

> Hacker News · 2026-08-31 · 브라우저/확장

---

보고된 내용에 따르면 구글이 Chrome Web Store에서 Manifest V2(MV2) 규격 기반 확장들을 제거했고, 그 목록에 인기 콘텐츠 차단기인 uBlock Origin이 포함된 것으로 전해진다. 피드 기준으로는 해당 조치의 구체적 사유나 적용 범위·일정 등 세부 정보는 제공되지 않아, 조치가 어떤 예외를 두는지 또는 기존 사용자의 동작에 어떤 영향이 있는지는 원문 확인이 필요하다.
기술적 맥락에서 MV2와 관련된 변경은 확장 API와 배포 정책에 직접적인 파급을 줄 수 있다. 개발자와 사용자는 콘텐츠 차단이나 네트워크 요청 제어 기능의 동작 변화 가능성을 염두에 둬야 하며, 제공된 메타데이터만으로는 영향의 범위와 대응 방안까지 단정하기 어렵다. 이 사안은 Hacker News에서 포인트 437·댓글 355로 큰 관심을 모으고 있다.
