# Making global data easier to explore

> Google Blog · 2026-09-17 · AI

---

UN 체계가 발표한 'UN System Data Commons'는 구글의 Data Commons 위에 구축된 오픈소스 플랫폼으로, 전 세계 통계를 하나의 AI‑준비 지식 그래프로 연결해 분석 전 처리에 드는 수개월의 수작업을 줄이려는 시도입니다. 여러 UN 기관에 흩어져 있고 서로 다른 형식으로 저장된 고신뢰 통계들을 자동으로 통합해 메트릭, 시간축, 지리 경계를 일관된 체계로 맞추며, 데이터 과학자나 정책 분석가가 포맷 변환 대신 추세 분석과 근거 기반 해법 설계에 집중할 수 있도록 설계돼 있습니다. 프로젝트에는 Google.org의 지원이 포함되며, 데이터는 UN 통계 전문가들이 검증합니다.
플랫폼은 자연어 검색과 대화형 탐색 기능을 통해 비전문가도 평문 질문으로 즉시 관련 데이터와 시각화를 얻을 수 있게 하고, 연구 워크플로우에 통합되는 AI 어시스턴트 기능도 제공합니다. 열린 표준인 Model Context Protocol(MCP)을 바탕으로 AI 에이전트가 공인 수치를 자율적으로 가져와 도메인 간 연계를 수행하고 차트·인포그래픽·초안 보고서 형태로 묶어낼 수 있도록 설계되었으나, 중요한 수치는 인용 전 근거를 직접 검토해야 한다고 명시합니다. 향후 2027년까지 UN 체계 통계의 약 80% 포함을 목표로 데이터와 기능을 확대할 예정이라는 점은 글로벌 데이터 인프라와 AI 기반 분석 도구의 상용화·확산 측면에서 기술적·정책적 시사점을 제공합니다.
