# Introducing Images 2.6

> OpenAI Blog · 2026-11-04 · Product

---

피드 기준으로는 OpenAI가 2026-11-04에 **Images 2.6**을 발표한 것으로 정리됩니다. 제공된 메타데이터에 따르면 이번 버전은 **더 빠른 이미지 생성**, **GIF 생성 기능**, **정밀한 이미지 편집** 그리고 **ChatGPT, Codex, API 전반에 적용되는 신규 API 제어**를 포함합니다.

변경사항은 제품 전반(대화형 인터페이스 및 개발자용 API)에 걸친 기능 확장으로 요약되며, 메타데이터만으로는 각 기능의 구체적 동작 방식, 성능 수치, 호환성 또는 출시 범위(예: 유료/무료, 리전별 차이 등)는 확인되지 않습니다. 원문은 OpenAI 블로그의 해당 게시물에서 공개된 것으로 보입니다(발행일: 2026-11-04).
