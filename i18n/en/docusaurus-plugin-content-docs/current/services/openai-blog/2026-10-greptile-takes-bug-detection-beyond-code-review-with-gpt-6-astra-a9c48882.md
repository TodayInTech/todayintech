# Greptile takes bug detection beyond code review with GPT-6 Astra

> OpenAI Blog · 2026-10-26 · Startup

---

피드 기준으로는 스타트업 Greptile이 OpenAI 블로그(2026-10-26 게시)를 통해 자사 버그 탐지 및 코드 품질 작업에 **GPT-6 Astra**, **Daybreak**, **Codex**를 각각 활용했다고 전해집니다. 메타데이터 요약에 따르면 GPT-6 Astra는 사용자 워크플로우 테스트에, Daybreak는 보안 강화에, Codex는 재작업 감소에 역할을 했다고 합니다.
