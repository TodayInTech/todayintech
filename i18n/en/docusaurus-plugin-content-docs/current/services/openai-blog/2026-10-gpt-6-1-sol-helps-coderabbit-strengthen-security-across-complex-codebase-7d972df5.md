# GPT-6.1 Sol helps CodeRabbit strengthen security across complex codebases

> OpenAI Blog · 2026-10-26 · Security

---

피드 기준으로는 OpenAI 블로그(2026-10-26)가 CodeRabbit이 **GPT-6.1 Sol**을 사용해 복잡한 코드베이스의 보안 리스크를 조사하고, 개발자가 결과와 제안된 수정사항을 검토하도록 돕는 보안 에이전트를 운영한다고 보고합니다. 제공된 메타데이터에 따르면 이 변화는 코드 취약점 탐지와 그에 대한 제안된 수정사항을 개발자 워크플로에 연결하는 것을 목표로 하는 것으로 보입니다. 원문 본문 내용 전체는 제공되지 않았으므로 기능의 상세한 작동 방식, 성능 지표, 통합 방법 등은 확인되지 않습니다. 출처: OpenAI 블로그(게시일 2026-10-26).
