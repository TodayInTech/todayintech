# Replit expands access to software creation with GPT-5.6 Luna

> OpenAI Blog · 2026-08-19 · Startup

---

Replit이 GPT-5.6 Luna로 구동되는 'Free Mode'를 도입해 누구나 아이디어를 실제 동작하는 소프트웨어로 전환할 수 있도록 했다는 소식이 피드 기준으로 전해졌다. 제공된 메타데이터는 이 모드가 토큰 비용에 대한 걱정 없이 코드 생성과 실행을 가능하게 한다고 요약하며, 구체적인 요금 체계나 기술적 제약 사항은 명시되어 있지 않다.
메타데이터만으로는 구현 세부사항을 확인할 수 없지만, GPT-5.6 기반의 무료 사용 모드는 프로토타이핑과 교육, 빠른 아이디어 검증 워크플로우에서 진입장벽을 낮출 잠재력이 크다. 다만 실제 성능, 사용 한도, 인프라 부담과 같은 운영적·비용적 변수는 원문 전체를 통해 추가 확인이 필요하다.
