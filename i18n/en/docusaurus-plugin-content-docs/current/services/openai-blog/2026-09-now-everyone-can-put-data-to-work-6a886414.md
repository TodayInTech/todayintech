# Now everyone can put data to work

> OpenAI Blog · 2026-09-10 · Product

---

OpenAI의 피드 요약에 따르면 ChatGPT Work에 새로 도입된 'Data agent'는 기업 데이터를 연결해 AI로 인사이트를 추출하고, 자연어로 상호작용하는 대시보드를 만드는 흐름을 지원하는 기능으로 소개된다. 피드 기준으로는 사용자가 내부 데이터에 접속해 질의하고 결과를 시각화·조작하는 워크플로를 자연어 인터페이스로 구현할 수 있게 하는 제품 업데이트로 보인다.
기술적으로는 AI를 직접적인 데이터 인터페이스로 삼아 분석 접근성을 낮추고 비전문가도 대화형 분석·대시보드 구축을 시도할 수 있게 하는 점이 의미가 있다. 다만 제공된 정보만 보면 구체적 커넥터 유형, 권한·보안 정책, 실시간 데이터 처리나 배포 방식 등 구현 세부는 확인되지 않아 실제 적용 환경에서는 추가 검증이 필요하다.
