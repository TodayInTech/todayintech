# Explore the Codex Security Plugin

> OpenAI Blog · 2026-11-19 · 데모

---

피드 기준으로는 OpenAI가 2026-11-19에 **Codex Security Plugin**의 데모 동영상을 공개했다. 제공된 요약에 따르면 이 녹화는 플러그인 사용의 전체 워크플로우—시작 방법에서부터 녹화에 표시된 결과를 검토하는 과정까지—를 시연한다.

영상 형식의 데모라는 점에서 실제 화면을 통해 흐름을 확인하려는 기술 독자에게 유용하다. 다만 피드 메타데이터만으로는 데모에 포함된 구체적 기능, 요구 조건, 설정 절차나 버전 정보 등 세부 기술 내용은 확인되지 않는다. 상세 내용과 녹화는 OpenAI 블로그의 해당 데모 페이지에서 확인할 수 있다.
