# Radisson Hotel Group brings hotel discovery into ChatGPT

> OpenAI Blog · 2026-10-07 · 여행 테크·AI 통합

---

피드 기준으로는 Radisson Hotel Group이 Accenture와 협력해 OpenAI 기술을 활용한 ChatGPT 플러그인을 선보였고, 이를 통해 여행자가 여행 계획 과정에서 호텔을 찾고 비교하며 예약까지 할 수 있도록 돕는다고 전합니다. 발표는 OpenAI 블로그에 게재되었고, 제공된 요약은 협업 주체와 기능 범위(검색·비교·예약)를 중심으로 간단히 설명합니다.
제공된 정보만 보면 구현 세부사항(예: 데이터 소스, 결제 흐름, 개인정보 처리, API 설계 등)은 확인되지 않으므로 기술적 평가에는 한계가 있습니다. 다만 대화형 에이전트 안으로 숙소 탐색·예약 기능을 직접 통합하는 점은 여행 테크와 대화형 상거래 분야에서 실용적 연결고리를 확장할 가능성이 있으며, 실제 적용 맥락과 운영 세부는 원문 확인이 필요합니다.
