# How avatarin built a 24/7 retail agent with GPT-Realtime

> OpenAI Blog · 2026-07-30 · AI 적용 사례

---

피드 기준으로는 OpenAI 블로그의 글이 avatarin이 OpenAI의 GPT‑Realtime을 활용해 일본 가전 체인 야마다 덴키 고객을 대상으로 24시간 다국어 지원 리테일 에이전트를 구축한 사례를 소개한다고 전한다. 제공된 요약에 따르면 서비스 출시 후 2주 동안 약 3만 명이 에이전트를 이용했고, 설문 응답의 92%가 긍정적이었다는 숫자가 제시되어 초기 도입 반응을 가늠하게 한다.
이 수치는 실시간 처리 능력을 강조하는 GPT‑Realtime 계열 모델을 고객 접점에 적용해 단기간에 높은 참여와 만족을 얻은 예로 해석될 수 있다. 다만 제공된 메타데이터만으로는 통합 아키텍처, 처리 지연·확장성, 지원 언어 범위나 구체적 응답 품질 같은 기술적 세부는 확인되지 않으므로, 원문과 추가 자료를 통해 구현 방식과 장기적 성과를 검증할 필요가 있다.
