# Amp puts AI agents to work beyond code with OpenAI models

> OpenAI Blog · 2026-10-14 · Startup

---

피드 기준으로는 OpenAI 블로그의 새 글이 Amp를 통해 에이전트의 적용 영역을 코드 밖으로 넓히려는 시도를 소개한다. 요약에는 GPT-6 Astra, Ultrafast, GPT‑Live‑1과 ‘Sign in with ChatGPT’가 나열되어 있어, Amp가 여러 최신 모델을 결합해 대화형·실행형 에이전트의 범위를 확장하려는 방향임을 암시한다.
제공된 정보만 보면 구체적 구현이나 적용 사례는 제시되지 않아 변화의 범위와 기술적 한계는 불명확하다. 기술 독자에게는 언급된 모델들이 갖는 실시간 처리 능력이나 성능·지연 특성, 그리고 ‘Sign in with ChatGPT’ 같은 인증·연동 기능이 실제 에이전트 동작에 어떤 영향을 미칠지가 핵심 관심사로 남으며, 원문에서 추가 세부 근거를 확인할 필요가 있다.
