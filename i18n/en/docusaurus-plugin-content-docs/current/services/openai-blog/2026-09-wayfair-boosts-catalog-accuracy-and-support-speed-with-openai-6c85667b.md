# Wayfair boosts catalog accuracy and support speed with OpenAI

> OpenAI Blog · 2026-09-25 · 전자상거래·AI

---

피드 기준으로는 Wayfair가 OpenAI 모델을 도입해 전자상거래 고객 지원과 제품 카탈로그 정확도를 개선했다는 내용으로 요약된다. 제공된 설명은 특히 고객 문의 티켓의 자동 분류(트리아주)를 통해 지원 처리 속도를 높이고, 수백만 건에 달하는 제품 속성을 대규모로 보정·향상시켜 카탈로그 품질을 개선했다고 전하고 있다.
이 사례는 자연어 모델이 운영형 워크플로우에서 티켓 라우팅과 구조화된 속성 추출·정정 같은 실무적 작업에 적용될 때 효용을 낼 수 있음을 시사한다. 다만 피드 메타데이터만으로는 사용된 모델 종류, 구현 방식, 성능 지표나 평가 방법 등 세부 정보가 제공되지 않아 실제 효과와 재현 가능성에 대한 판단은 제한적이다. 기술 독자는 핵심 주장과 적용 범위를 참고해 추가 근거를 확인하는 것이 필요하다.
