# Check if a text message is a scam using Circle to Search.

> Google Blog · 2026-10-15 · Safety &amp; Security

---

스미싱 등 문자 기반 사기가 정교해지는 가운데, 구글의 Circle to Search 기능은 안드로이드 사용자가 의심스러운 문자 메시지를 빠르게 검토해 잠재적 사기를 식별하도록 돕는 실용적 도구로 소개된다. 사용자가 링크를 클릭하거나 개인정보를 공유하기 전에 메시지를 시각적으로 선택해 AI가 제공하는 'AI Overview'에서 가이드와 인사이트, 권장 조치를 한눈에 확인할 수 있다는 점이 핵심 주장이다. 글은 도구가 사기 신호를 드러내면 메시지 삭제와 발신 번호 차단을 고려하라고 권고하는 등 실무적 대응 방안까지 연결해서 제시한다.
활용 방법은 단순하다. 안드로이드에서 홈 버튼이나 네비게이션 바를 길게 눌러 Circle to Search를 활성화하고, 불확실한 메시지를 원으로 감싸면 AI 요약과 다음 단계 제안이 나타난다고 설명한다. 이 흐름은 제로 클릭 조사와 같은 전통적 검색 절차보다 사용자 행동의 장벽을 낮추고, 메시지 내 위험 요소를 빠르게 분류해 사용자 결정을 지원하는 점에서 기술적·운용적 의미가 있다. 다만 원문은 기능의 작동 방식이나 개인정보 처리 세부사항, 지원 기기 범위 등 추가 기술적·정책적 조건은 다루지 않으므로 적용 전에 해당 내용의 확인이 필요하다.
