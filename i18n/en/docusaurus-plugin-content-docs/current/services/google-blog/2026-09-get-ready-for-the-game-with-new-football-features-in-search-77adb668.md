# Get ready for the game with new football features in Search

> Google Blog · 2026-09-09 · Search

---

미국 풋볼 시즌을 맞아 구글 검색이 실시간 경기 경험과 개인화된 판타지 지원을 결합한 여러 기능을 내놓았습니다. 검색에서 경기 중인 시합을 검색하면 빨간 ‘Live’ 아이콘과 함께 Live Game Feed를 통해 경기 요약, 플레이별 타임라인, 주요 비디오 하이라이트, 소셜 코멘터리와 AI 기반 통찰을 실시간으로 확인할 수 있습니다. 현재 프로 풋볼용 라이브 피드는 미국 모바일(영어)에서 제공되며, 이달 말에는 대학팀 지원과 전 세계 확장도 예정되어 있습니다. 경기별 점수 확인을 간편하게 하는 matchup 캐러셀도 도입돼 리그 전반의 다른 경기 점수를 따로 검색하지 않아도 한눈에 볼 수 있습니다.
검색 결과의 통계 표현도 강화됩니다. 시즌별 리그 리더(패싱 터치다운, 러싱 야드 등)와 함께 섹스, 펌블, 획득 야드(YAC) 같은 상세 선수 지표가 추가되고, 곧 챔피언십 우세팀과 플레이오프 대진표도 보여줄 예정입니다. 판타지 사용자에게는 Yahoo Fantasy와 Sleeper 계정을 AI Mode에서 안전하게 연동해 실시간 로스터 정보를 바탕으로 스타트/싯 추천, 웨이버 타깃, 드래프트 평가 및 주간 요약을 받을 수 있게 했고, 수동 입력이나 스크린샷이 필요 없다고 명시합니다. 사용자 피드백은 AI Mode 응답에서 좋아요·싫어요로 전송할 수 있으며, 이들 업데이트는 검색을 단순 정보 창을 넘어 실시간 이벤트 데이터, 소셜 신호, AI 분석, 서드파티 계정 연동이 결합된 개인화 허브로 확장하려는 기술적 방향성을 보여줍니다.
