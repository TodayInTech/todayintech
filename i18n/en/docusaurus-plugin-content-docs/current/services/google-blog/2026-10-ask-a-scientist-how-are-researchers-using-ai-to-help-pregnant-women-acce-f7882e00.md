# Ask a Scientist: How are researchers using AI to help pregnant women access ultrasounds?

> Google Blog · 2026-10-06 · Healthcare/AI

---

구글 연구진이 전통적 초음파 접근성이 낮은 지역에서 비전문가가 간단한 촬영만으로도 임신 관련 핵심 정보를 확보할 수 있도록 한 연구를 소개한다. 연구팀은 자카란다 헬스(Jacaranda Health)와 노스웨스턴 의대와 협업해 나이로비와 시카고에서 각 1,000명의 산모를 대상으로 ‘블라인드 스윕’ 방식의 초음파 영상을 수집했다. 이 방식은 탐촉자를 복부에 정해진 패턴으로 훑어 영상을 얻는 방법으로, 기존 초음파사처럼 정교한 탐촉자 조작 능력이 없어도 활용할 수 있다. 연구에서는 현장 보건인력이 8시간 교육만으로 블라인드 스윕을 수행할 수 있었고, 머신러닝 모델이 수집된 영상을 기기 내에서 분석해 재촬영 필요 여부를 알려주고 임신주수와 태아 위치를 숙지된 초음파사와 유사한 정확도로 판별했다고 보고한다.
기술적 의미는 접근성과 확장성에 있다. 전통적 초음파 장비는 크고 비싸며, 인력 부족과 전력·유지보수 문제로 저자원 환경에서 제약이 크다. 연구에서 사용한 소형·배터리 기반 장치와 기기 내 연산은 네트워크나 안정적 전력 공급이 불안한 환경에서도 즉시 진단 정보를 제공할 수 있다는 점을 강조한다. 이 접근법은 임신주수 산정과 태아의 자세 확인처럼 출산 준비와 긴급 대처에 결정적 영향을 미치는 정보를 더 많은 지역에 전달할 잠재력이 있으며, 추후 다른 임상적 적용으로 확장될 여지도 시사한다.
