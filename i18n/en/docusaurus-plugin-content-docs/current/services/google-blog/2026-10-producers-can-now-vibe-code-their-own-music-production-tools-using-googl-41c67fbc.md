# Producers can now vibe code their own music production tools using Google Flow Music.

> Google Blog · 2026-10-06 · 음악 제작/프로덕션

---

Google Flow Music의 Spaces는 제작자가 자연어로 맞춤 악기나 이펙트를 설계할 수 있게 해, 코딩 경험 없이도 개인 작업 흐름에 맞춘 도구를 만들 수 있도록 한다. 이제 이 기능을 전문 작업 환경으로 바로 연결할 수 있도록 Spaces에서 제작한 맞춤 도구를 VST3·AU 규격의 플러그인으로 내보내 DAW 내에서 직접 실행할 수 있다는 점이 기사 핵심이다. 이 변화는 익숙한 프로덕션 환경을 벗어나지 않고도 커스텀 처리 체인을 활용할 수 있게 해, 제작 스타일과 프로세스에 맞춘 툴을 손쉽게 배치하는 흐름을 가능하게 한다.
예시로 프로듀서 Khris Riddick-Tynes가 만든 ‘No Chaser’ 플러그인은 녹음 환경이 달라도 악기와 보컬의 선명도를 유지하도록 설계되었다고 소개된다. 피드의 설명에 따르면 이런 워크플로 통합은 사용자 맞춤형 도구를 표준 플러그인 포맷으로 변환해 기존 DAW 기반 제작 파이프라인에 끼워 넣을 수 있다는 점에서 기술적·실무적 의의가 있다. 다만 제공된 근거는 기능의 개요와 한 가지 사례를 중심으로 하고 있어, 내부 작동 방식이나 지원되는 세부 옵션·제한 등에 관해서는 추가 정보가 필요하다.
