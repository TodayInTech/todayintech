# Anthropic Economic Index: Insights from Claude 3.7 Sonnet

> Anthropic Blog · 2026-08-25 · 인공지능·경제분석

---

Anthropic이 발표한 두번째 Anthropic Economic Index 보고서는 Claude 3.7 Sonnet 출시 이후 11일간의 100만 건(익명)의 Claude.ai 대화를 분석해 모델 사용의 경제적 의미를 추적한 결과를 담고 있습니다. 보고서는 Sonnet 출시 이후 코딩 비중과 교육·과학·헬스케어 관련 사용이 소폭 증가했음을 보고하며, Sonnet의 ‘extended thinking’ 모드는 주로 컴퓨터·정보 연구자(약 10%), 소프트웨어 개발자(약 8%), 멀티미디어 아티스트(약 7%), 비디오 게임 디자이너(약 6%) 등 기술적·창의적 과제에서 빈번히 활성화된다고 밝힙니다. 증강(augmentation)과 자동화(automation)의 전체 비중은 이전 보고서와 유사하게 증강이 약 57%를 차지했고, 학습적 상호작용(정보·설명 요구)은 약 23%에서 28%로 늘어났습니다. 작업·직업 수준의 세부 분석에서는 카피라이터·편집자 관련 과제가 인간과 모델의 반복적 협업(탐색적 반복)이 높은 반면 번역가·통역가 관련 과제는 지시적 사용(모델 단독 수행)이 많은 등 직군별 차이를 제시합니다.
보고서는 또한 O*NET 기반의 상향식 한계를 보완하기 위해 Clio로 동일 데이터에서 도출한 630개 세분화 클러스터의 바텀업 사용 분류를 공개합니다. 예시로 수자원 관리, 물리 기반 시뮬레이션, 배터리 기술 안내, 폰트 선택 지원 등 실제 사용자 사례가 포함되며 각 클러스터에 자동화·증강 비중과 유병률이 연결되어 연구자가 상향식·하향식 접근을 비교·확장할 수 있도록 설계되었습니다. 데이터와 추가 산출물(각 O*NET 업무별 extended thinking 사용률 등)은 공개 저장소(Hugging Face)에 제공되며, 분석 방법론에서는 안전 분류기 기반 필터링과 Sonnet 적용으로 Clio 분류 정확도가 향상되었다고 기술합니다. 이러한 자료는 모델 성능 변화가 노동시장·업무 구조에 미치는 영향을 지속적으로 측정하려는 후속 연구에 실무적 기반을 제공합니다.
