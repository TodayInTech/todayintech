# Frontier model security

> Anthropic Blog · 2026-08-26 · AI 보안

---

Anthropic은 최첨단(frontier) AI 모델의 역량이 빠르게 커지는 상황에서 모델과 연구를 도난이나 악용으로부터 지키기 위해 일반 상용 기술 수준을 훨씬 넘어선 보안 조치가 필요하다고 주장한다. 회사는 단기적으로는 모델 가중치와 연구 자산 보호에 집중해야 하며, 이를 위해 업계 전반에 널리 확산시킬 강력한 모범 사례 개발과 ‘중요 인프라’에 준하는 공공·민간 협력이 필요하다고 제안한다. 권고안은 초기에는 자율적 합의로 시작할 수 있지만, 시간이 지나면 정부 조달이나 규제권을 통해 준수를 강제하는 방안이 적절할 수 있다고 본다.
기술적 권고로는 두 사람 통제(two-party control)와 다자 승인(multi-party authorization)을 AI 개발·학습·호스팅·배포 전반에 적용할 것을 강조한다. 이는 내부자 위험과 고도로 자원화된 위협 행위자를 방어하기 위한 설계로, 누구도 영속적 생산 환경 접근권을 갖지 않게 하고 시간 제한적 접근을 동료 승인으로 관리하도록 한다. 또한 NIST의 SSDF와 SLSA 같은 보안 소프트웨어 개발·공급망 표준을 모델 개발 과정에 확장해 '체인 오브 카스티디(증빙 가능한 출처 추적)'를 확보하자고 권한다. Anthropic은 이미 이러한 제어·표준을 도입 중이며 향후 정부와 업계와의 협의를 통해 점진적으로 보안 수준을 높여가겠다고 밝힌다. 전반적으로 제안된 조치들은 모델 출처 추적성과 내부자 위험 완화, 그리고 조달을 통한 시장 전반의 보안 향상이라는 실용적 의미를 가지며, 정책적 수단과 기술적 실천을 병행할 필요성을 분명히 한다.
