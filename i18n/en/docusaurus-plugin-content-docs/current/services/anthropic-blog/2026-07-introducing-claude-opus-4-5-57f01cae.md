# Introducing Claude Opus 4.5

> Anthropic Blog · 2026-07-23 · 인공지능·모델 발표

---

Anthropic가 발표한 Claude Opus 4.5는 코딩, 에이전트 작업, 일반적인 컴퓨터 활용에서 ‘최고 수준’이라고 회사가 규정한 신형 모델입니다. 회사는 Opus 4.5를 앱·API·주요 클라우드에서 즉시 제공하며, 모델 식별자(claude-opus-4-5-20251101)와 토큰 기반 가격($5/$25 per million tokens)을 공개했습니다. 내부 및 고객 초기평가를 근거로 Opus 4.5는 복잡한 다중 시스템 버그 해결, 코드 리팩터링·마이그레이션, 장시간 자율 코딩 세션 등에서 우수한 성과를 보였다고 주장합니다. 또한 긴 대화 유지, 스프레드시트·브라우저·데스크톱 통합 등 제품 연동이 강조됩니다.
성능·효율성 측면에서 Anthropic은 여러 정량적 개선을 제시합니다. Terminal Bench에서 Sonnet 4.5 대비 15% 향상, 일부 작업에서 최대 65%까지 토큰 사용 절감, 도구 호출·빌드/린트 오류 50~75% 감소, 엑셀 자동화 내부 평가에서 정확도 20%·효율 15% 향상 등의 수치가 예시로 제시됩니다. 모델의 ‘effort’ 파라미터와 컨텍스트 컴팩션·메모리·서브에이전트 관리 기능은 개발자가 속도·비용·성능 사이의 트레이드오프를 조정하게 해주며, Claude Code의 Plan Mode·데스크톱 병렬 세션·Chrome·Excel 통합 등 실제 도구 개선으로 연결됩니다. 안전성 면에선 Opus 4.5가 Anthropic 기준에서 지금까지 가장 잘 정렬된 모델이며, 프롬프트 인젝션 저항성도 향상되었다고 명시합니다. 원문은 평가 설정과 방법론(생각 예산, 컨텍스트 창 등)과 시스템 카드 참조를 함께 제공해 결과 해석의 근거를 제시하고 있어, 조직의 도입 검토·비용 추정·에이전트화 워크플로우 설계에 실질적 단서를 줍니다.
