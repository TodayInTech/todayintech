# Donating Agent Skills to the Agentic AI Foundation

> Anthropic Blog · 2026-10-22 · AI 표준/거버넌스

---

Anthropic이 개발한 Agent Skills는 AI 에이전트에 특정 지식과 작업 흐름을 가르치는 간단한 폴더 기반 표준으로, SKILL.md 파일과 필요 스크립트·참고자료를 포함하는 구조를 통해 에이전트 간 상호운용성을 목표로 한다고 소개합니다. Claude Code를 개발하면서 일반 지식 처리에 비해 실제 업무의 절차적 지식이 부족하다는 문제를 해결하기 위해 만들어졌고, 2025년 10월 공개 이후 수천 개의 스킬이 GitHub에 올라왔고 Codex·Cursor·OpenCode용 로더가 작성되는 등 빠르게 채택되어 왔습니다. 2025년 12월 표준 공개 이후로는 ChatGPT, Cursor, GitHub Copilot, VS Code 등 70여 플랫폼이 통합했고 지금까지 100만 개의 스킬이 게시되고 약 2.8억 건이 설치되었다고 명시됩니다.
Anthropic은 이 표준을 오픈·커뮤니티 주도·벤더 중립으로 유지하기 위해 Agentic AI Foundation(AAIF, Linux Foundation 산하)에 Agent Skills의 이름·로고·GitHub 조직·agentskills.io 도메인 등을 기부한다고 밝혔습니다. 유지 관리는 Anthropic·Google·OpenAI 등 엔지니어 개인들이 담당하며 David Soria Parra와 Mahesh Murag가 리드 메인테이너로 지정되었습니다. 제안된 다음 단계는 버전화 릴리스, 정식 제안 절차, 스킬 작성·설치자를 위한 보안 가이드 등으로, 과거 Model Context Protocol의 사례처럼 투명한 커뮤니티 의사결정과 입력을 우선시하겠다는 점이 강조됩니다. 기술적 의미는 간단한 형식의 표준과 중립적 거버넌스가 에이전트 생태계의 상호운용성과 확장성을 촉진할 수 있다는 점이며, 제안된 버전·제안 절차·보안 지침이 실제로 구현되면 운영 신뢰성·생산성 측면에서 실무적 영향을 줄 가능성이 큽니다.
