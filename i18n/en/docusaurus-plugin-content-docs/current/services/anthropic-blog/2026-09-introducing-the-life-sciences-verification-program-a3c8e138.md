# Introducing the Life Sciences Verification Program

> Anthropic Blog · 2026-09-17 · AI·생명과학

---

Anthropic이 발표한 Life Sciences Verification Program(LSVP)은 생명과학 전문가에게 Mythos, Opus, Sonnet 모델을 보다 관대해진(생물학 관련 작업에 허용적) 보호체계로 제공하는 베타 프로그램이다. 연구 자격·보안 기준·윤리적 감독을 검토하는 검증 절차를 통해 팀 단위로 Standard Use 또는 High-risk Use 두 가지 보조금(grant)을 신청할 수 있다. Standard Use는 대부분의 연구·개발·임상·제조·품질관리 등 일상적 생명과학 업무를 대상으로 하며 Mythos 5.1·Opus 5·Sonnet 5에 적용돼 연간 갱신된다. 반면 High-risk Use는 특정 프로젝트 수준에서 표준 차단을 해제하는 추가 심사형 권한으로 6개월 단위 갱신이며, 현재 Opus·Sonnet에 대해 사용 가능하고 Mythos 고위험은 제한적으로 제공 중이다.
LSVP의 설계는 악용 시나리오(계정 탈취·내부자 위협·에이전트 오용)를 염두에 둔 공유 책임 모델에 바탕을 둔다. 실시간 차단에서 오프라인 모니터링으로 전환해 세션·요청에 걸친 패턴을 식별하고, 기관이 신청 시 명시한 용도 범위와의 일치 여부를 계속 감시해 조직 관리자에게 이상 사용을 통보한다. 이를 위해 LSVP 트래픽은 검토 목적상 30일간 데이터 보존이 요구되며, 보존 데이터는 모델 학습에 사용되지 않고 엄격히 분리된다고 명시했다. 또한 기존의 사이버 분류기 등 다른 보호장치는 유지된다. 현재 LSVP는 엔터프라이즈·팀 콘솔과 API, Claude Science에서 지원되며 개인 플랜·서드파티 플랫폼·BAA 대상 PHI 사용자는 제한을 받는다. 전반적으로 LSVP는 생명과학 워크플로우를 넓히는 동시에 데이터 보존과 모니터링을 통한 리스크 관리라는 실무적·윤리적 절충을 명확히 제시한다.
