# 10 technical talks I’m excited about at GitHub Universe 2026

> GitHub Blog · 2026-10-01 · Company news

---

Senior Developer Advocate인 Andrea Griffiths가 GitHub Universe 2026에서 개인 일정의 기준으로 삼은 10개 기술 세션을 모아 개발자 관점의 우선순위를 제시한다. 그녀는 ‘에이전트가 작성한 코드가 실제로 동작하는지’, ‘에이전트가 무엇을 기억해야 하고 무엇을 잊어야 하는지’, ‘의존성을 설치할 때 우리가 신뢰하는 것은 무엇인지’ 같은 실무적 질문을 바탕으로 세션을 골랐다. 발표자와 주제는 에이전트 메모리·평가·권한, JavaScript 툴링, 네트워크가 불안정한 환경에서의 소프트웨어 설계 등 현업에서 즉시 적용 가능한 문제들을 다룬다.
구체적 세션으로는 npm 설치 과정의 권한과 릴리스·프로비넌스 문제를 다루는 발표, Copilot의 메모리 설계와 누적 맥락이 성능에 미치는 영향을 벤치마크로 분석한 연구, 에이전트 컨텍스트를 팀 전체의 인프라로 다루는 실무적 접근, 호스트된 MCP 서버 앞에 per-identity 권한을 추가하는 아이덴티티-어웨어 프록시 데모, 그리고 실전 평가에서 무엇을 측정하고 무엇을 중단했는지에 대한 Copilot 팀의 인사이트가 포함된다. 이밖에 에이전트가 AI 생성 코드를 검증하는 방법, 결함 원인 분석(RCA) 에이전트의 아키텍처 분리, GitHub Actions의 공급망 공격 대응 프레임워크, Vite+를 이용한 JavaScript 툴체인 마이그레이션 사례, 연결성이 낮은 커뮤니티를 위한 오프라인 설계 경험담 등 기술적 주제가 고르게 포진해 있어 도구 선택과 보안·평가·운영 관점에서 실무적 판단에 바로 도움이 될 만한 내용들로 구성되어 있다.
