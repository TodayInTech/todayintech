# GitHub Copilot app for Beginners: Getting started

> GitHub Blog · 2026-07-27 · 개발자 도구 / AI 보조 코딩

---

GitHub Copilot 앱은 단순한 채팅 인터페이스를 넘어서 실제 개발 흐름을 지원하는 작업공간을 지향한다. 에이전트 세션은 프로젝트 컨텍스트와 연결되어 특정 작업에 필요한 코드베이스와 파일, 도구를 바로 사용할 수 있게 해 주므로 환경 준비 시간을 줄이고 곧바로 작업을 시작할 수 있다. 동시에 여러 세션을 열어 버그 수정, PR 검토, 코드 탐색 같은 서로 다른 스레드를 병행할 수 있으며, 홈 화면에서 Quick Chat을 통해 별도 대화를 빠르게 띄워 컨텍스트 전환 없이 참고용 질의나 조사성 질문을 처리할 수 있다.
브라우저 캔버스 기능은 UI 변경 결과를 워크플로 내에서 바로 미리보기하고 조정할 수 있게 해 준다. /create-canvas 명령으로 애플리케이션을 캔버스에 띄우고, Canvas Dev Mode의 Pick &amp; Polish로 화면 요소를 직접 선택해 다음 요청의 문맥으로 사용할 수 있다. 코드 변경 이후에는 Agent Merge를 통해 PR을 모니터링하고 리뷰 피드백 대응, CI 실패 해결, 머지 충돌 처리 등 반복적인 리뷰 업무를 자동화 보조하는 흐름을 제공한다. 요약하면 이 앱은 프로젝트 연결 세션, 시각적 캔버스, PR 자동 보조를 결합해 일상 개발 작업의 중단을 줄이고 AI를 실무 워크플로에 통합하는 선택지를 제시한다.
