# Octoverse: Commits, pushes, reach new highs in 2026 as developers build with agents

> GitHub Blog · 2026-10-28 · Developer Platforms

---

GitHub의 2026년 Octoverse는 플랫폼 상의 활동량이 전례 없이 급증했고, 특히 AI 코딩 **에이전트(agent)** 채택이 개발 흐름을 바꾸고 있다고 보고했다. 측정 창(2025-10-01 ~ 2026-09-30) 기준으로 지난 12개월간 개발자가 GitHub에 코드를 푸시한 횟수는 **17.9 billion(179억)**, 전체 커밋은 **34.3 billion(343억)**, 병합된 풀 리퀘스트는 **1.3 billion(13억)**에 달한다.

## 에이전트가 바꾼 작업 방식
보고서는 에이전트의 확산이 작업속도와 워크플로에 실질적 차이를 만들었다고 분석한다. **올해 생성된 리포지토리 중 에이전트 설정 파일이 있는 리포지토리는 없는 리포지토리보다 평균 8배 더 많은 커밋**을 기록했고, 2026년 9월에는 전체 풀 리퀘스트의 **40% 이상(9월에만 1.1억 건)** 이 에이전트의 초안으로 시작됐다(3월에는 17%). 에이전트 시작 PR은 다중 파일 변경 비율이 더 높고(약 87% 대 79%), 병합 속도도 2월 대비 개선되어 9월에는 약 90%가 2주 내 병합되었다.

또한 GitHub Copilot 사용자의 모델 선택 행동도 빠르게 분화했다. 2026년 9월 기준 Copilot 사용자의 **61%가 세션에서 둘 이상의 모델을 사용**했고, 5월의 29개 모델에서 9월에는 47개 모델로 늘어났다. 개발자가 명시적으로 선택한 요청 중 모델별 비중은 일반 목적 38%, 심층 추론·계획 37%, 빠른 모델 25%로 보고되었다. Project HydraFusion(보고서 언급)은 현재 GitHub Copilot Fusion으로 일반 제공되어 여러 모델을 계획·조율하는 흐름을 지원한다.

## 규모·자동화·보안 지표
자동화·보안 지표도 동반 상승했다. GitHub Actions는 초당 평균 **1,440개 작업**, 일일 약 **1.24억** 작업을 실행했고, Dependabot을 통한 병합 PR은 3천만 건을 넘어 작년보다 두 배 수준이었다. 푸시 보호(노출된 비밀 감지)는 **58억 회**의 스캔을 수행해 2025년 대비 거의 4배 증가했다. 오픈 소스 공헌은 공개 리포지토리 기준으로 **25억**으로 2025년(11.2억)보다 두 배 이상 늘었다.

보고서는 이러한 변화가 모델·하네스(도구)·에이전트의 동시 진화와 클라우드 기반 실행 확대로 인해 가속화되었다고 본다. 근거는 플랫폼 텔레메트리와 기능별 사용 지표(에이전트 신호, 모델 선택, Actions/Dependabot/보안 기능 사용량)이다.

분석적 유의점: 보고서는 탐지 가능한 '에이전트 신호'를 기준으로 집계했으며, 모든 에이전트 사용이 포착되지는 않을 수 있다(보고서의 'agent signal' 정의 참고). 또한 모델 사용 통계는 개발자가 직접 모델을 선택한 요청만 집계한 수치(오토 셀렉션, 스태프 사용 등은 제외)임을 근거가 명시하고 있다.

이 보고서는 에이전트 도구를 초기에 도입한 리포지토리와 팀이 훨씬 더 많은 변경을 만들고 있음을 수치로 확인시켜 주며, 개발자 경험과 자동화·보안 도구의 동시 강화가 플랫폼 활동을 견인한 것으로 보인다.
