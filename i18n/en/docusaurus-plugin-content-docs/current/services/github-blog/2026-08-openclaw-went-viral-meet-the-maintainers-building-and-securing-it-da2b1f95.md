# OpenClaw went viral. Meet the maintainers building and securing it.

> GitHub Blog · 2026-08-27 · Open Source / Security

---

Peter Steinberger가 주말 실험으로 시작한 개인용 AI 비서 OpenClaw는 출시 6개월 만에 약 388,000 스타, 81,000 포크, 80,000여 커밋을 기록하며 GitHub 역사상 가장 빠르게 성장한 프로젝트로 떠올랐습니다. 급증한 참여는 수천 건의 풀 리퀘스트와 자동화된 ‘프롬프트 요청’ 폭주로 이어졌고, 유지관리자들은 유의미한 기여를 찾아내는 문제로 전환해야 했습니다. 이 과정에서 비개발자도 에이전트를 이용해 PR을 만들고 유지관리자와 협력해 완성하는 사례가 늘었고, 제출물의 신뢰도를 판단하기 위해 에이전트 대화록, 스크린샷, 테스트 증거 같은 새로운 신호가 중요해졌습니다. 또한 유지관리자들은 AI로 생성된 코드 검토에 GitHub Copilot 같은 도구를 적극 활용하고 직접 PR을 편집해 수정하는 관행을 일상화했습니다.
보안 측면에서는 에이전트 기반 기여의 편의성과 위험 사이에서 균형을 찾는 일이 핵심 과제로 부상했습니다. 중복 PR, 자동화된 PR 공장, 기업의 프로모션용 자동 PR 등 소셜 신호가 조작될 수 있는 현실이 드러났고, 최근 공급망 공격들은 핵심 의존성 재검토와 의존 대상 프로젝트와의 직접적 관계 형성을 촉발했습니다. GitHub Secure Open Source Fund 참여자들은 보안 관행을 배우고 유지관리자 커뮤니티와 경험을 공유하며 ‘무엇을 요청할지 아는 능력’을 키웠다고 평가합니다. 기술적으로는 에이전트·자동화가 만든 대규모 기여를 처리하려면 새로운 리뷰 신호, 자동화된 검토 도구 통합, 안전한 기본값 설계, 그리고 의존성 거버넌스와 커뮤니티 협력이라는 실무적 변화가 필요하다는 교훈을 남깁니다.
