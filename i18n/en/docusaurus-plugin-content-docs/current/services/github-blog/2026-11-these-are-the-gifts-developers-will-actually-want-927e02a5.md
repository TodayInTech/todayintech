# These are the gifts developers will actually want

> GitHub Blog · 2026-11-24 · Company news

---

GitHub는 개발자를 위한 휴일 선물 가이드를 공개했다. GitHub Shop에서 추천하는 상품군으로는 **GitHub x Omnitype Bauer Lite Keyboard Kit**(랜덤 색상 조합·핫스왑 PCB with RGB 언더글로우·Omnitype Hawk 리니어 스위치·염색승화 PBT 키캡 및 조립 도구), 지그소 퍼즐, 데스크 매트·머그·Copilot Amazeball·Mona Octobobble 같은 데스크 장식, 여행용 토트·테크 오거나이저·스케이트보드, Invertocat 후디·onesie·Mona 인형 등 다양한 카테고리가 포함된다. 프로모션으로 코드 **FREESHIPBLOG26**을 사용하면 2026년 12월1일까지 표준 배송비가 면제되며, 선물 도착을 위해 12월22일까지의 배송 마감일을 확인하라고 안내하고 있다. 제공된 근거에는 각 상품의 가격·재고·국가별 배송 제한 등 상세 조건은 포함되어 있지 않다.
