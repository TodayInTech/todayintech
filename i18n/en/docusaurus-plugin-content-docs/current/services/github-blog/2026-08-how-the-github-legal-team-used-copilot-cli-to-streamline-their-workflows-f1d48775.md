# How the GitHub legal team used Copilot CLI to streamline their workflows

> GitHub Blog · 2026-08-04 · AI &amp; ML

---

GitHub 법무팀의 사례는 코드 작성 능력이 없는 직군도 GitHub Copilot CLI로 자체 도구를 빠르게 만들고 업무 방식을 재구성할 수 있음을 보여준다. 제품 담당 변호사 Ngandu Kasuku는 저장소에 핵심 문서와 지침을 모아 버전 관리하며 ‘terms‑ai’라는 계약 초안 도구를 만들었다. 이 도구는 내부 스타일 가이드와 과거 합의를 참조하는 라이브러리를 활용해 복사·붙여넣기와 변형을 줄였고, 그 결과 초안 및 검토 시간이 대략 절반으로 줄었으며 산출물의 문체와 조항 일관성이 향상되었다고 보고한다. 민감한 합의서는 공개 리포지토리에 포함하지 않는 방식으로 구조를 분리한 점도 명시되어 있다.
온라인 안전 담당 Jesse Geraci는 처음에는 DMCA 관련 코드 분석과 분류를 자동화하려는 좁은 목표로 시작했지만, 플레인랭귀지로 작성한 워크플로 지침·정책 참조·보고서 템플릿을 중심으로 시스템을 확장하면서 데스크톱 앱으로 발전시켰다. 이 앱은 코드 비교·라이선스 확인·NDA 트리아지·리스크 평가 등 다양한 사내 법무 워크플로를 지원하며, 내부적으로는 인입, 플레이북 정렬, 리스크 스코어링, 증거 검증, 에스컬레이션, 보고서 조립 같은 재사용 가능한 스킬과 에이전트로 작업을 라우팅한다. 핵심 메시지는 복잡한 벤더 솔루션이나 전업 개발자가 아니어도 명확한 방법론과 출력 형식을 정의하면 Copilot CLI로 판단과 절차를 구조화해 일관성·투명성·확장성을 높일 수 있다는 점이다. 다만 도구는 법적 판단을 대체하지 않고 인간 검토를 중심에 둬야 한다는 점을 저자들이 분명히 밝히고 있다.
