# GitHub Copilot app for Beginners: Using the diff, terminal, and browser

> GitHub Blog · 2026-09-10 · AI &amp; ML

---

GitHub Copilot 앱은 에이전트가 만든 코드 변경을 검토하고 실행하며 미리보는 과정을 하나의 창에서 끝낼 수 있도록 세 가지 내장 패널(diff, terminal, browser)을 제공한다. diff 패널은 추가된 줄을 초록, 삭제된 줄을 빨강으로 하이라이트해 변경 내용을 한눈에 보여주며 사용자는 변경을 수용하거나 코멘트를 달고 Copilot에게 수정 요청을 보낼 수 있다. 터미널 패널에서는 세션 안에서 프로젝트의 명령을 직접 실행하고, Run 버튼으로 스크립트를 돌리거나 여러 터미널을 열어 작업을 전환할 수 있다(예: dev server, npm run dev). 브라우저 패널은 사용자 인터페이스가 있는 변경사항을 실제로 열어 확인하고 Pick &amp; Polish 도구로 요소를 선택해 에이전트와 함께 조정하는 흐름까지 지원한다.
이처럼 검토·실행·미리보기를 한 자리에서 수행하면 탭을 오가는 수고를 줄이고 에이전트가 만든 변경을 실제로 증명해가며 병합하는 과정이 쉬워진다. 변경을 만족할 때는 앱에서 바로 수용하고 풀 리퀘스트를 생성할 수 있어 개발 흐름이 매끄러워진다. 덧붙여 문서에는 제어된 오프라인 평가에서 HydraFusion의 선택적 코딩 워크플로가 평가된 Opus 5 기준을 맞추거나 상회했고 워크플로 비용을 줄였다는 결과와 함께 해당 기능이 GitHub Copilot의 연구용 프리뷰로 제공된다고 명시돼 있어, 단순한 사용 편의성 개선을 넘는 실험적 연구 통합의 징후도 확인된다.
