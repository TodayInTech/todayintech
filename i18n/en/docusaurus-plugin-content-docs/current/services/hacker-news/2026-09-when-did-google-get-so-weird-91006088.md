# When did Google get so weird?

> Hacker News · 2026-09-27 · Search / AI

---

작성자는 단순히 과거 NBA 밈 관련 트윗을 찾기 위해 'hes never coming over dario'라는 검색어를 입력했는데, 구글의 AI 개요가 사용자의 의도를 오독해 '감정적 위로'를 제공하려 든 경험을 공유한다. 맥락 설명으로 2014년 드라기오 사리치의 사례와 팬들이 썼던 밈을 짚은 뒤, 기대했던 건 과거 트윗이나 링크였지만 대신 AI 개요가 마치 '상심한 사람'을 위로하는 문체로 응답했다고 설명한다. 실제로 원하는 링크는 AI 영역 아래로 스크롤해야 보였다는 점을 명확히 제시한다.
이 개인적 사례는 기술적·설계적 시사점을 안긴다. 저자는 검색 엔진의 본래 목표인 '정보 조직과 접근성'과 대비해, 대화형 LLM이 검색 결과를 주도할 때 발생하는 의도 불일치와 기계의 '정서적 대응'이라는 낯선 상호작용을 문제 삼는다. 또한 Gemini 같은 채팅형 앱에서는 어느 정도 허용될 수 있는 응답도 전통적 검색 인터페이스로 제공될 때는 사용자 기대와 충돌한다는 점을 지적한다. 이 사례는 검색 결과 페이지에서 생성형 답변과 링크 중심 정보 탐색을 어떻게 분리·표시할지, 사용자 의도를 정확히 판별하는 시스템 설계가 왜 중요한지에 대한 실무적 논쟁을 촉발할 만한 근거를 제공한다.
