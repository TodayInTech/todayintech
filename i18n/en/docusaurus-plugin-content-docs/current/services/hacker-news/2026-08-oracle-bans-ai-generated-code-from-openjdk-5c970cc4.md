# Oracle bans AI-generated code from OpenJDK

> Hacker News · 2026-08-07 · 오픈소스·AI 정책

---

Oracle이 OpenJDK 기여물에 대해 AI(LLM)로 생성된 코드의 제출을 금지했다. 공개된 규정에 따르면 개발자들은 개인적으로 LLM을 디버깅이나 코드 검토 용도로 사용할 수는 있지만, AI가 생성한 산출물은 저장소·풀리퀘스트·프로젝트 채널 등 공식 기여 경로에 제출할 수 없다. 회사는 이 같은 제한을 안전성·보안·지적재산 위험을 근거로 제시하고 있어 오픈소스 유지관리 차원에서의 책임과 위험 관리를 우선시한 결정으로 읽힌다.
이 방침은 Oracle 내부에서의 AI 활용 주장과 뚜렷한 대조를 이룬다. 공동창업자 래리 엘리슨은 “Oracle의 코드를 AI 모델이 작성한다”고 밝힌 반면 최고경영진은 AI 도구가 소규모 엔지니어링 팀의 생산성을 높였다고 평가했다. 한편 Oracle은 데이터센터 확장에 올해 700억달러를 투자하고 있으며, 이 같은 대규모 지출에 대해 S&amp;P가 수익성 불확실성을 이유로 신용등급을 BBB-로 강등했다. 오픈소스 기여에 대한 엄격한 금지와 내부의 공격적 AI·인프라 투자가 병행되는 점은 지적재산·보안 관리와 AI 의존도의 실무적·재무적 함의를 모두 드러낸다.
