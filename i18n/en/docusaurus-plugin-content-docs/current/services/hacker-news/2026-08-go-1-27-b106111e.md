# Go 1.27

> Hacker News · 2026-08-19 · Programming / Go

---

Go 1.27은 언어와 도구, 런타임, 표준 라이브러리에 걸쳐 실용적 진화를 제시한다. 언어 측면에서는 제네릭 메서드가 도입되어 동일한 타입 패턴을 여러 메서드로 분리하던 필요가 줄어들고, 구조체 리터럴에서 중첩·임베디드 필드의 선택자를 직접 키로 쓸 수 있게 되어 초기화 문법이 간결해졌다. 아울러 제네릭 함수의 타입 추론이 합성 리터럴, 타입 변환, 채널 송신 등 모든 할당 문맥으로 일반화되어 제네릭 코드를 더 폭넓게 명시적 타입 인자 없이 재사용할 수 있다. 도구 측면에서는 go fix의 여러 modernizer, go doc의 package@version 쿼리 지원, 그리고 go mod tidy의 require 블록 통합 등 일상적 개발 흐름을 개선하는 변화가 포함됐다. 런타임에서는 80바이트 미만 소형 객체 할당 비용을 최대 30% 줄이는 사이즈 특화 할당으로 할당 집약적 프로그램의 전체 성능이 대략 1% 개선되고, 영구적으로 블록된 고루틴을 자동 탐지하는 goroutineleak 프로파일이 정식화되었다.
표준 라이브러리 변화는 호환성과 성능, 보안에서 주목된다. encoding/json/v2와 저수준 스트리밍용 jsontext를 통해 보다 엄격한 기본값과 구성 옵션을 제공하며, 기존 encoding/json은 v2 구현으로 백엔드가 교체되어 언마샬링 성능이 빨라졌다(하위 호환성 유지). 암호화 영역에서는 포스트-양자 ML-DSA(FIPS 204)를 구현한 crypto/mldsa가 crypto/x509와 crypto/tls에 통합되어 향후 양자 내성 서명 지원 경로를 마련했고, uuid 패키지의 네이티브 지원과 실험적 SIMD 패키지(simd, simd/archsimd)는 특정 워크로드에서 성능 실험과 간편한 UUID 처리에 도움을 준다. 또한 net/http/httptest의 NewTestServer는 testing/synctest와 함께 메모리 내 가짜 네트워크 환경을 제공해 테스트 작성 편의성을 높인다. 전체 변경사항과 세부는 릴리스 노트를 통해 확인할 수 있으며, 향후 블로그 후속 포스트들이 일부 주제를 더 깊게 다룰 예정이다.
