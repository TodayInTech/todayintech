# Pi 1.0

> Hacker News · 2026-10-01 · AI 에이전트 도구

---

Pi가 1.0에 도달하면서 '단순함'을 유지하되 안정성과 확장성을 강화한 에이전트 하니스로 정식 공개됐다. 글은 Pi가 수개월간 사용자 피드백과 PR을 통해 다듬어졌고, 이미 매주 수십만 사용자가 쓰는 일상적 코딩 에이전트였음을 밝힌다. 1.0에 포함된 주요 추가 기능으로는 Codemode(네이티브 MCP 및 Jev·이미지 등 비-LLM 모델 지원), 가상 모델을 위한 확장 지원, 도구의 지연 로딩, Anthropic 모델용 캐시 워밍, 대화 중 시스템 메시지(대화 전사 인식 프롬프트·도구 변경)와 같은 실용적 개선들이 언급된다. 또한 새로운 TUI 테마와 기본 전체화면 모드 등 사용성 측면의 변화도 포함되어 있어, 기존의 '미니멀' 철학을 유지하면서도 운영환경에서의 신뢰성·유연성이 늘었다는 점이 핵심 주장이다.
동시에 Earendil은 Pi의 미니멀리즘을 장기 실행되는 에이전트 애플리케이션으로 확장하려는 실험적 패키지 Pi Durable을 함께 공개했다. Pi Durable은 빌더와 사용자가 장기 대화와 작업을 보다 정교하게 조종할 수 있게 하는 새로운 서브스트레이트로 소개되며, Pi의 핵심 원칙을 이어받되 장기성(durability)을 추가한 점이 차별화 포인트다. 배포 방식과 접근성도 명시되어 있어 바로 설치·확인이 가능하다(curl/PowerShell 설치 명령과 npm 패키지, MIT 라이선스, 문서와 GitHub 저장소 안내가 제공됨). 기술적으로는 다양한 모델 공급자 지원과 도구 로딩·프롬프트 관리 개선으로 실무적 통합 비용을 낮추고, 장기 작업을 다루는 에이전트 설계 실험에 유용한 기반을 제공할 가능성이 크다.
