# Show HN: Open-Source eInk Bike Computer

> Hacker News · 2026-09-04 · 하드웨어/오픈소스

---

이 프로젝트는 4.7인치 전자종이(e-paper) 패널을 쓴 오픈소스 자전거 컴퓨터로, 직사광선에서도 읽기 쉽고 SD 카드 슬롯을 통해 오프라인 지도, 경로, 라이딩 로그를 저장할 수 있도록 설계되었습니다. 한 보드에 GPS, 정전식 터치, 전면 라이트, 배터리, USB-C를 통합했고, 심박·파워·케이던스 같은 센서와는 Bluetooth 5로 연동됩니다. 펌웨어는 데스크톱용 Chromium 브라우저를 통해 USB로 설치할 수 있어 개발자와 사용자가 직접 업데이트하거나 커스터마이즈하기 편리합니다. 이러한 구성은 야외에서의 가독성과 오프라인 내비게이션, 센서 호환성 측면에서 실용적 이점을 줍니다.
반면 설계상 절충점도 분명합니다. 기압 고도계가 없어 상승고도는 측정값이 아니라 지도 타일에 기반한 추정치로 처리되며, GPS 모듈은 기본형이라 다중 주파수 모듈에 비해 위성 고정 속도와 수신 유지력이 떨어질 수 있습니다. 나침반(자력계) 부재로 정지 상태에서는 지도 방향을 자체적으로 가리키지 못하고, 1,500mAh 구성 기준으로 실사용 시간은 약 7.4시간 내외로 측정되었습니다. 하드웨어 버튼이 약하고 방수 처리가 되어 있지 않아 비나 추위 상황에서는 케이스나 방수 대책이 필요하다는 점도 명확한 제약입니다. 이런 장단점은 오픈소스 하드웨어를 직접 쓰거나 개선하려는 개발자·제작자에게 명확한 설계 우선순위와 개선 대상(배터리·GPS·방수·입력 방식)을 제시합니다.
