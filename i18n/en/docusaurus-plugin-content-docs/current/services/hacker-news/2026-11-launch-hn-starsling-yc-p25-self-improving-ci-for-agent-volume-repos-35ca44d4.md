# Launch HN: StarSling (YC P25) – Self-improving CI for agent-volume repos

> Hacker News · 2026-11-17 · CI/CD / DevOps

---

StarSling은 GitHub Actions용 빠른 Ubuntu 러너에 AI 에이전트를 결합해 워크플로우 자체를 지속적으로 최적화한다고 발표했다. 회사 측 설명에 따르면 사용자는 워크플로우의 runs-on 레이블을 한 줄만 바꾸면 StarSling 러너로 전환할 수 있으며, 에이전트는 실행 로그·머신 텔레메트리·워크플로우를 분석해 성능·캐시·병렬화 개선안을 PR로 제안한다.

## 하드웨어·요금·설치 방식
- 러너는 Zen 5(5th Gen AMD EPYC) 기반의 빠른 머신을 사용하며, 설치는 기존 워크플로우에서 runs-on: ubuntu-latest를 runs-on: starsling-ubuntu-26.04(또는 ubuntu-24.04 대응)로 바꾸는 방식이다. 회사는 하드웨어 전환만으로도 큰 시간 단축이 가능하다고 설명한다.
- 요금은 예시로 4 vCPU/16GB 러너가 **$0.008/분**(GitHub 호스티드의 $0.012/분 대비 33% 저렴)이고, 새 유료 구독은 초당 과금(초 단위, 부분초 올림)을 지원한다. 신규 계정은 첫달 2,000분 무료다.

## 에이전트 루프와 자동 최적화
StarSling의 CI 하니스는 에이전트 루프를 돌려서: (1) 워크플로우·로그·텔레메트리 분석, (2) 최적화 제안, (3) 변경 전후를 병렬로 비교 테스트, (4) 통계적으로 유의미하면 PR로 제출하는 흐름을 설명한다. 에이전트가 만든 PR은 유저가 검토·병합할 수 있으며, 최적화 PR 기능은 유료 플랜에서 기본 비활성화다. 회사는 에이전트 PR이 지속적으로 파이프라인을 개선한다고 주장한다.

## 실사용 사례와 성능 지표(회사 제공)
- Mastra: 테스트 스위트 p95 **29m 56s → 5m 06s (약 5.87×)**, E2E 2m22s→1m04s, 큐 대기 시간 9.5분→35초 등 수치를 제시했다.
- Better Auth: 11개월 된 병목을 잡아 한 테스트 잡을 **5.4×** 가속한 PR을 예로 든다.
- 공개 벤치마크에서 러너+에이전트 PR 조합으로 최대 **10×**까지 개선했다고 회사가 표기.

이들 수치는 StarSling이 제공한 사례·벤치마크에 근거한 것이며, 외부 검증 여부는 문서에 명시돼 있지 않다.

## StarSling Disks·GPU·리뷰 러너
- **StarSling Disks**: 영구 마운트된 디스크로 pnpm 저장소 등 의존성을 미리 준비해두며, Mastra의 4.5GiB pnpm store에서 의존성 준비 시간이 약 25초로 **actions/cache 대비 4.5×** 빨랐다고 밝혔다. 저장소 요금은 **$0.50/GB-month**.
- **GPU 러너**: 전용 NVIDIA 카드(예: RTX PRO 6000 $0.06422/분, RTX 5090 $0.03022/분, RTX 4090 $0.02522/분; H100 예정)를 레이블로 지정해 잡별로 다른 카드를 선택 가능하다.
- **Review Runners**: PR을 StarSling 러너로 리뷰하는 워크플로우를 제공하며, 리뷰는 사용자의 모델 키·스킬·스크립트를 사용해 실행된다. 리뷰 러너는 별도 요금(예: $0.004/분) 구조를 제시한다.

## 보안·운영 모델 (회사 설명)
각 잡은 일회용 하드웨어 격리된 마이크로VM에서 실행되며 작업 종료 후 소멸한다고 설명한다. GitHub에서 시크릿은 잡으로 직접 전달되고 StarSling이 시크릿을 저장하지 않는다고 명시되어 있다. 또한 실패한 잡의 실행 시간은 과금 대상이며 큐 대기 시간은 과금하지 않는다고 밝혔다.

## 실무적 시사점(증거 기반 해석)
- 간단한 전환: Linux 기반 GitHub Actions 워크플로우라면 runs-on 레이블 하나로 시험 전환해 즉시 성능 차이를 확인할 수 있다(문서상의 주장).
- 에이전트 PR은 CI 유지·개선 부담을 덜어줄 가능성이 있으나, 회사도 지적하듯 에이전트·코드 생성기가 PR 볼륨을 크게 늘려 CI 비용·큐 병목을 악화시킬 수 있다. StarSling은 무제한 동시성·초당 과금·고성능 러너로 이 패턴을 수용하는 설계라고 주장한다.

제공된 근거는 스타트업의 제품·벤치마크·요금표·사례 중심으로 구성되어 있어 독자는 실무 전환 전에 자체 검증(벤치마크, 보안·비용 시뮬레이션)을 권장한다.
