# Read this before you buy that TV streaming stick

> Hacker News · 2026-07-30 · Security / IoT

---

한 연구자가 만료된 도메인을 확보해 들여다본 결과, 특정 저가형 TV 스트리밍 스틱(H96)이 단순한 불법 스트리밍 용도를 넘어 조직적 광고 사기와 거주 프록시 제공에 동원되고 있다는 사실이 드러났습니다. Bitsight의 Pedro Falé는 수만 대의 H96 기기에서 수집된 원격 텔레메트리를 분석해, 해당 기기들이 자신을 삼성·Vivo·화웨이·샤오미 등 모바일폰으로 위장해 AI로 생성된 웹사이트의 광고를 클릭하도록 조작된 정황을 확인했습니다. 이들 기기에 설치된 앱들은 Zhejiang Fengwo IoT Technology(운영명 Fengwo Group)와 연결되며, 회사 측은 Blockly 시각적 프로그래밍 환경을 이용해 기술력이 낮은 운영자도 광고 클릭·브라우징·탭 관리 같은 사기 루틴을 쉽게 배포하도록 설계해 둔 것으로 보입니다. 또한 봇이 페이지 내 광고를 식별하도록 세 가지 비전·추론 시스템을 결합해 사람이 수행하는 것처럼 정교하게 동작합니다.
Bitsight은 H96 기기들이 사용자의 TV가 켜져 있을 때는 주로 주거용 프록시 트래픽을 중계하고, TV가 꺼졌을 때는 광고 사기 작업을 수행하도록 전환된다고 보고했습니다. 분석 대상 도메인에 접속한 기기가 약 3만8천대에 달했고, 이 네트워크의 일일 수익은 보수적으로 약 5만 달러에 이른다고 추정됩니다. 해당 기기들이 기본적으로 인증 없이 취약하게 출하되는 점, 주요 전자상거래 채널에서 다양한 비공식 Android 기반 모델이 판매되는 현실은 개인과 기업 네트워크에 직간접적 위험을 야기합니다. 기사 근거는 이름 있는 제조사 제품과 Play Protect 인증 여부 확인, 그리고 Synthient의 악성 사전 설치 목록을 통해 소비자 주의가 필요하다고 권고합니다.
