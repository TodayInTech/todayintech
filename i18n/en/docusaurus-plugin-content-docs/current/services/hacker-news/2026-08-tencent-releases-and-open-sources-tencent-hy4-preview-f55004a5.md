# Tencent Releases and Open-Sources Tencent Hy4 Preview

> Hacker News · 2026-08-29 · AI / LLM

---

텐센트가 Hy4 preview를 공개하고 오픈소스로 배포했다. 이 모델은 전체 7700억(770B) 파라미터, 활성 파라미터 490억(49B), 그리고 100만 토큰을 넘는 컨텍스트 창을 갖추었다고 소개되며, 코딩·오피스·과학연구 등 실무적 생산성 과제에서 뛰어난 성능을 발휘한다고 밝혔다. Hy4 preview는 WorkBuddy·CodeBuddy·Yuanbao·ima 등 텐센트 제품을 통해 글로벌로 접근 가능하며, Tencent Cloud TokenHub와 OpenRouter를 통한 API 연결도 제공된다. 출시 시점에는 WorkBuddy·CodeBuddy에서 2주 무료 체험이 제공되고, Hy3의 무료 제공 기간도 9월 30일까지 연장되었다. 내부 블라인드 평가(163명 전문가, 203개 엔지니어링 과제)에서는 평균 2.99/4.00을 기록해 비교 대상인 GLM-5.3(2.92)과 Kimi K3(2.94)보다 근소하게 앞섰다.
기술적으로 Hy4 preview는 사전학습과 사후학습의 개선, 도메인 전문 데이터(소프트웨어, 게임, 금융, 보안 등)와 제품 공동설계를 통해 실제 작업 흐름에서의 이해·계획·디버깅·검증 능력을 끌어올렸다고 설명한다. 긴 컨텍스트가 요구되는 개발 작업, 교차문서 협업을 포함한 데이터 분석과 문서·스프레드시트·프레젠테이션 생성, 자연어에서 플레이어블 프로토타입을 만드는 게임 개발 워크플로우, 그리고 분자역학·응집물질물리·기초수학 등 과학 연구 문제 해결에서의 개선이 주요 적용 사례로 제시된다. 흥미로운 점은 모델이 자체적으로 학습·데이터·평가·연산자 최적화 실험에 참여해 초기 단계의 자기개선 루프를 형성했고, 추론 시스템 병목을 분석해 연산자 융합·통신 최적화 등을 통해 엔드투엔드 처리량을 기준 대비 31.8% 향상시켰다는 주장이다. 또한 API 가격(입력 토큰·출력 토큰·캐시 히트 기준)과 프리뷰 우선 방식으로 제품 피드백을 연구에 반영하는 운영 전략도 함께 안내되어 있다.
