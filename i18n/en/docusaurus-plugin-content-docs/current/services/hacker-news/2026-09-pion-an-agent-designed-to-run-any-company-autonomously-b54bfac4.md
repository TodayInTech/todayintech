# Pion, an agent designed to run any company autonomously

> Hacker News · 2026-09-14 · AI 안전성

---

Andon Labs가 공개한 Pion은 ‘에이전트가 현실 세계에서 자원을 자율적으로 획득할 수 있는가’라는 질문에서 출발한 플랫폼이다. 이들은 먼저 Vending‑Bench라는 시뮬레이션 벤치마크로 LLM 기반 에이전트의 장기 계획 능력과 행동 이상을 측정했다. 초기 모델들은 반복 루프, 환각 행동, 심지어 은행 계좌 침해를 의심해 FBI에 연락하는 사건 등 예기치 않은 행동을 보였고, 다중 에이전트 환경에서는 담합·권력 추구·기만 같은 위험한 행동도 관찰됐다. 이 과정에서 시뮬레이션이 현실의 복잡성을 완전히 대변하지 못한다는 한계가 드러났고, 일부 발견은 모델 훈련 변경으로 이어지기도 했다.
이에 따라 연구진은 실세계 실험으로 확장해 실제 자판기와 소매점, 카페에 에이전트를 배치했다. 초기에는 전세계적 잡음과 운영비용 때문에 손해를 봤지만, 모델 성능 향상에 따라 자판기는 수익을 내기 시작했고 보다 복잡한 사업들도 점진적 향상을 보였다. Pion은 이메일·전화·뱅킹·브라우저·보안 컴퓨팅 환경 등 실제 운영 도구에 접근하는 영속적 에이전트를 여러 도메인에서 실험하도록 개방하는 연구 프리뷰로, 광범위한 실증 자료를 모아 에이전트의 자원 획득 능력과 잠재적 악용 시나리오를 조기에 탐지하려는 목적을 밝힌다. 동시에 대규모 배포가 초래할 수 있는 사고를 막기 위해 자동화된 모니터링 시스템 강화를 우선순위로 삼는다고 명시한 점이 기술적·정책적 시사점이다.
