# Claude Opus 5.5 Intelligence, Performance and Price Analysis (Max)

> Hacker News · 2026-09-22 · AI 모델 분석

---

Claude Opus 5.5(Adaptive Reasoning, Max Effort, Default Fallback)는 Anthropic이 발표한 추론형 멀티모달 모델로, 텍스트·이미지 입력을 받아 텍스트 출력을 생성하고 최대 100만 토큰(약 1500 A4 페이지)에 달하는 대규모 컨텍스트 창을 지원한다. 인공분석(Artificial Analysis) 지수에서 58점을 기록해 비교 대상(reasoning 모델 및 유사 가격대 모델군) 대비 상위권에 속하지만, 같은 분석에서 생성한 출력 토큰량이 2억6천만 토큰으로 중간값 88M보다 매우 높은 편이라 응답이 대체로 장문·verbose하다는 특성이 드러난다. 모델은 체인오브소트(extended thinking) 형태의 추론 방식을 사용하며, 비추론(non-reasoning) 변형이 존재할 수 있음을 명시한다.
가격 측면에서는 입력 토큰당 $4.00, 출력 토큰당 $20.00로 보고되어 동일 가격대 다른 모델들에 비해 다소 고가로 평가된다(중간값 각각 $2.00, $10.00). 제공된 예시 비율(cache hit·입력·출력 7:2:1)을 적용한 혼합 단가는 약 $2.94/1M 토큰으로 산정되며, Intelligence Index 평가를 실행하는 데에는 총 $8,708.20가 소요되었다고 명시되어 있다. 모델 가중치는 공개되지 않은 폐쇄형(proprietary)이고 파라미터 수 역시 비공개라 상호비교 시 한계가 있으나, 높은 점수·거대한 컨텍스트·멀티모달 능력은 장문 추론·문서 기반 분석이나 이미지 포함된 복합 질의 처리 같은 응용에서 잠재적 이점을 제공한다. 다만 출력 토큰 과다 사용과 상대적 비용 상승은 실무 도입 시 비용-성능 균형을 재검토해야 할 요소로 남는다.
