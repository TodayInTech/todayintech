# Discord will soon let anyone find public server messages through Google

> Hacker News · 2026-10-27 · 플랫폼·프라이버시

---

**Server Web Page 도입과 일정**
Discord는 Discoverable Servers(최소 **1,000명** 회원, Server Discovery에 등록된 서버)를 대상으로 **Server Web Page**를 자동으로 생성한다고 발표했다. 공지에 따르면 **2026년 11월 16일**부터 모든 Discoverable Server에 페이지가 생기며, 이 페이지에는 공개 채널의 토픽을 바탕으로 생성된 **Channel Summaries**가 표시될 수 있다. 일부 공개 채널의 개별 메시지는 **2026년 12월 중순**부터 웹 및 검색에 노출되기 시작하며 노출은 점진적으로 롤아웃되므로 첫 메시지 노출까지 몇 주가 걸릴 수 있다.

## 관리 제어와 사용자 제어의 분리
서버 관리자는 공지 기준으로 **즉시(공지 게시일부터)** Server Settings &gt; **Web Presence**에서 어느 채널을 참여시킬지 선택하거나 모든 채널을 옵트아웃할 수 있다. 개별 사용자는 User Settings &gt; **Data and Privacy**에서 자신의 메시지가 표시되는 것을 끌 수 있는데, 이 설정은 **Discoverable Server의 모든 채널 메시지**에 대해 하나의 설정으로 적용된다. 한편 **Channel Summaries는 별도로 생성**되며, 요약은 관리자가 끄지 않는 한 Server Web Page에 계속 표시될 수 있다. Server Web Page에 표시되는 메시지에는 사용자명과 아바타가 함께 나오지 않는다.

## 범위와 예외
이 변경은 Discoverable Servers에만 한정된다. **개인 서버, DM, GDM은 항상 비공개**로 유지되며 이번 변경에 포함되지 않는다.

## 실무적 의미
사실: Discord는 공개 서버 콘텐츠의 웹·검색 노출을 허용하고, 관리자와 사용자에게 각각 옵트아웃 경로를 제공한다(설정 위치와 일정 포함).
해석: 공개 서버 운영자는 외부 검색을 통한 유입과 가시성 증가를 기대할 수 있으나, 동시에 공개 메시지 노출에 따른 프라이버시·콘텐츠 관리 부담이 커질 가능성이 있다. 실무적으로는 관리자가 Server Settings &gt; Web Presence에서 참여 채널을 사전에 검토해 옵트아웃 정책을 결정하고, 커뮤니티 공지로 사용자에게 Data and Privacy 설정 위치와 영향을 안내하는 것이 직접적으로 필요한 조치다.

중요 표기: 공지에 명시된 날짜와 설정 경로는 원문 근거에 따른 것이며, Channel Summaries의 노출은 사용자 메시지 옵트아웃과 별개로 관리자가 통제해야 한다는 점이 핵심 제약이다. (근거: Discord 공지)
