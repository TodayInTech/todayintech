# OpenCode 2.0

> Hacker News · 2026-10-14 · Developer Tools

---

OpenCode 2.0은 사용자 수백만의 사용 패턴을 바탕으로 한 대대적인 개편으로, 로컬에서 단일 백그라운드 프로세스로 동작하는 중앙 서비스 모델을 기본으로 삼아 TUI·웹·데스크톱 앱과 동일한 프로세스에 연결되도록 변경했다. @opencode/client를 통한 자동 발견으로 스크립트와 예약 작업에서 서비스 호출이 매끄럽게 이루어지며, opencode api와 CLI를 통한 접근, 다른 호스트와의 페어링 기능도 지원한다. 기존에 무질서하게 성장한 API는 처음부터 재설계되어 세션을 git worktree로 옮기는 등 환경-aware한 동작을 수행하고, JS와 Effect용 클라이언트 패키지가 제공된다.
기술적으로 눈에 띄는 변화는 코드를 에이전트 내부에서 네이티브로 실행하도록 한 Code Mode다. @opencode/codemode의 경량 JavaScript 인터프리터는 MCP 서버나 OpenAPI 엔드포인트를 함수로 변환해 노드 VM이나 복잡한 임베딩 없이도 스크립트 호출과 도구 합성을 단일 라운드 트립으로 처리하게 한다. 또한 백그라운드 서브에이전트와 비동기 셸 커맨드를 도입해 장기 실행 작업을 포그라운드 흐름을 막지 않고 처리할 수 있으며, 작업을 수동으로 백그라운드로 옮기는 단축키도 제공한다. 플러그인 구조는 80여 개의 내부 플러그인으로 강화되어 플러그인 API 유지보수를 보장하고, SDK(@opencode/sdk)를 통해 서버 환경이나 Durable Objects 같은 특수 환경에 OpenCode를 라이브러리로 포함시켜 표준 서버 프로토콜로 클라이언트와 연결할 수 있다. 업그레이드는 파괴적 변경이 있어 1.x 플러그인 호환 불가, 서버 API 변경, tui.json 설정 위치 이동 등을 유념해야 한다.
