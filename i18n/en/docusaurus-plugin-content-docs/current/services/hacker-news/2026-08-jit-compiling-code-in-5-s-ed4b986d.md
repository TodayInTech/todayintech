# JIT Compiling Code in 5μs

> Hacker News · 2026-08-23 · 시스템/컴파일러

---

글은 전통적으로 어렵던 JIT 컴파일러 개발이 AI 보조를 통해 훨씬 수월해졌고, 그 결과 pgrust 프로젝트에서는 쿼리별 JIT을 가능하게 하는 초저지연 컴파일(약 5μs)을 달성했다고 소개한다. 저자는 간단한 정규식 엔진을 예제로 삼아 인터프리터와 손수 작성한 네이티브 코드, 그리고 JIT으로 생성한 코드 간 성능을 비교한다. JIT은 런타임에 확보되는 정보(예: 입력 문자열의 구조)를 활용해 2–20배 수준의 성능 개선을 가능하게 하며, pgrust에서는 AI가 어셈블리 수준의 코드 생성 작업을 보조해 JIT 개발 장벽을 낮춘 점을 핵심 주장으로 제시한다.
구현 관점에서 글은 copy-and-patch 방식의 ‘스텐실’ 접근을 상세히 다룬다. 반복되는 명령 시퀀스를 템플릿으로 준비해 정규식 AST 기준으로 채워넣고 연결하여 실행 가능한 어셈블리 프로그램을 만들며, 예제로는 ARM64(macOS) 타깃의 코드 흐름을 단계별로 보여준다. 백트래킹을 위한 스택·널 종료 문자열을 이용한 길이 검사 회피·레지스터 할당(x0: 포인터/리턴값, x1/x2: 백트래킹 스택, x9: 임시) 같은 설계 결정이 설명되어 있고, 실제로 mmap(MAP_JIT)으로 메모리를 확보한 뒤 pthread_jit_write_protect_np로 쓰기 권한을 토글하고 캐시 무효화(sys_icache_invalidate)로 코드 실행을 보장하는 macOS 특유의 절차가 제시된다. 벤치마크 표는 해석기 대비 10–20배, 손수 짠 코드와는 대체로 동등한 성능을 보이며 JIT이 실무적 대안이 될 수 있음을 뒷받침한다. 이러한 기술적 세부는 JIT을 새로 도입하거나 데이터베이스·파싱 성능을 개선하려는 개발자들에게 직접 적용 가능한 인사이트를 제공한다.
