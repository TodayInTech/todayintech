# Tcl/Tk 9.1

> Hacker News · 2026-09-29 · 오픈소스/개발도구

---

Tcl/Tk 9.1.0 개발 릴리스는 2026년 9월의 안정화 릴리스를 목표로 9.0 기반 위에 여러 기능과 API 개선을 더한 업데이트다. Tcl 측에서는 Unicode 정규화 지원을 위한 새 명령 unicode와 C 루틴(Tcl_UtfToNormalized*), 모노토닉 클럭과 마이크로초 해상도를 제공하는 timer 명령, 리스트에서 항목을 골라내는 lfilter, 자식 인터프리터 변수 접근을 위한 interp set 등 스크립트 수준의 편의성이 강화됐다. subst에 대한 세부 옵션(-backslashes, -commands, -variables)과 switch의 -integer 옵션, 그리고 많은 C99 수학 루틴을 expr 함수로 노출한 점은 문자열·수치 처리에서의 일관성과 성능·표현력을 높인다. 내부적으로는 초기화 루틴(Tcl_FindExecutable 또는 TclZipfs_AppHook) 호출 의무화, Tcl_IsEmpty 등 신규 C 유틸리티, 리스트 객체를 위한 Tcl_ListObjRange/Repeat/Reverse, long long 기반의 새로운 시간 API와 64비트 크기 지원 확장, 대형 리스트의 메모리 효율 개선 등 런타임·확장성 측면의 변화가 포함된다. 또한 macOS에서 대소문자 구분 없는 파일 경로 처리, Windows의 auto_execok·exec 검색 개선, 스크립트 라이브러리와 인코딩 검색의 개정도 눈에 띈다.
Tk 측 변화는 사용자 인터페이스의 현대화와 접근성 향상에 초점이 맞춰졌다. 스크린리더 지원과 초기 단계의 양방향(우측-좌측, RTL) 텍스트 처리가 추가되어 국제화·접근성 측면에서 의미 있는 진전이 있다. 새 위젯 ttk::toggleswitch와 tk attribtable 명령, Aqua에서의 send 명령 개선, 음수 화면 거리 처리 보완, ttk::treeview·ttk::notebook의 확장된 상태 처리, Tk_CanvasTextInfo 개선과 라벨의 회전 텍스트 지원 등 위젯·렌더링 기능이 확장되었다. 메시지 박스·다이얼로그의 물리적 화면 너비 제한, 리스트박스 선택 색상 개선, Windows XP 외형 지원 제거 등은 현대적 플랫폼 기준에 맞춘 정리 작업이다. 전반적으로 이번 개발 릴리스는 문자 인코딩·타이밍 정밀도·메모리·64비트 호환성 및 UI 접근성 개선을 중심으로 실무적 이점과 마이그레이션 고려사항을 함께 제공한다.
