# EDG C++ front-end goes public

> Hacker News · 2026-09-30 · Compilers / 프로그래밍 언어

---

2026년 9월 30일, 30년 동안 업계에서 사용된 EDG의 C++ 프런트엔드 소스가 공개되었고 관리 주체는 비영리 단체인 The C++ Alliance로 이관되었습니다. 공지문은 이것이 '진로의 변화가 아닌 관리자의 변화'라며 연속성을 강조합니다. EDG는 그동안 생산 수준의 유일한 소스-투-소스 엔진으로 여러 컴파일러와 도구의 핵심으로 쓰여 왔고, 이제 동일한 엔진과 표준 구현을 공개된 저장소(github.com/edgcpp/compiler)에 담아 누구나 기여할 수 있게 되었습니다. 핵심 연락자와 엔진 자체는 그대로 유지된다고 명시되어 있습니다.
개발과 유지보수는 세 개의 트랙으로 운영됩니다. 사용자 PR을 통한 기여는 기존 경험 있는 EDG 개발자들이 검토해 동일한 공개 코드베이스에 병합되고, Alliance 소속 개발자들이 수행하는 유지보수 작업은 즉시 공개됩니다. 대규모 기능은 커뮤니티 자금으로 후원받아 개발한 뒤 모두에게 동시에 공개되는 모델을 도입해, 조직이 개발자를 파견하지 않고도 기능을 지원할 수 있도록 했습니다. 재정 모델도 연간 라이선스에서 세제 혜택이 가능한 기부 기반으로 전환되며, 이를 감독하는 재정후원위원회(FSC)는 John Spicer가 의장을 맡고 사용자 자원봉사자를 포함해 운영될 예정입니다. 이 전환은 EDG를 사용하는 컴파일러·도구 개발자들에게 코드 접근성과 거버넌스 참여 경로를 열어주며, 전문적 유지보수와 커뮤니티 주도의 확장 경로를 병행하도록 설계된 것이 기술적 의미입니다.
