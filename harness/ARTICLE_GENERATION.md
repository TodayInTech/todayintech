# 동적 아티클 생성 검증

## 변경 범위

Collector → Preprocessor → Enrichment → Writer → Docusaurus 구조와 기존 메타데이터·중복 방지 상태는 유지한다. Writer 응답에 `article_markdown_ko`만 추가하고 `summary_ko`는 목록용 1~2문장으로 사용한다. 상세 본문은 Markdown으로 저장하고 목록은 표준 `description` frontmatter를 읽는다. 기존 문서는 본문 문단 추출 방식으로 계속 읽힌다. 이미 발행된 글은 재생성하지 않는다.

## 실제 생성 비교

2026-06-13에 보관한 원문 근거 3건을 재사용해 기존 프롬프트와 개선 프롬프트를 `gpt-5-mini`로 실행했다. 각 전후 비교의 입력 chunk는 동일하며, 입력·출력 토큰 예산은 늘리지 않았다. 분량은 공백·Markdown 문자를 포함한 본문 문자 수이고 정확히 같은 문장의 반복만 자동 집계했다. 생성은 비결정적이며 이 표는 최종 프롬프트의 후보별 1회 결과다. 프롬프트 조정 과정의 시행 결과를 평균한 수치가 아니다.

## 근거 및 내용 점검

- GitHub: 검증 단계만 변경한다는 점, 파일 수준 사용 맥락, 목표 65%와 오탐 감소 75.76%, 고객 확인 오탐 수백 건이라는 평가 범위를 대조했다. 작성자 소개와 관련 글의 Qubot을 이번 작업에 사용했다고 연결하지 않는 것을 확인했다.
- DiffusionGemma: 26B/3.8B, 256토큰 병렬 생성, 최대 4배, H100 1000+·RTX 5090 700+ 토큰/초, 양자화 시 18GB VRAM, Gemma 4 대비 낮은 출력 품질과 저동시성 환경의 이점을 대조했다. `llama.cpp` 지원은 이미 완료된 것으로 바꾸지 않고 예정 상태를 유지했다. 공개자의 성능 주장을 재현 실험으로 검증한 것은 아니다.
- OpenAI·Oracle: 적격 Universal Credits, OCI 접근 경로, '향후 몇 주'라는 상대적 가용성 안내를 보존했다. 특정 모델 버전·확정 출시일·요금·인증 API·보안 보장을 새 사실로 단정하지 않았는지 검토했다.
- 최종 3건의 trace 근거 ID는 전달된 chunk ID 안에 있다. 단순 공지는 소제목 없이 3문단, 기술 발표는 5개 소제목으로 달라졌다. 본문과 목록 요약은 별도로 생성됐다.
- 완전히 같은 문장의 반복은 없지만, 이 지표만으로 의미상 중복이나 모든 사실의 정확성이 보장되지는 않는다. 짧은 공지의 도입/마지막 문단에는 구매 경로의 의미를 재서술하는 경향이 남아 있어 지속적인 표본 검토가 필요하다. 3건은 품질 예시이며 전체 서비스에 대한 정확도 평가가 아니다.

## 근거 확보 검토

기존 Enrichment는 4,000토큰 이하 원문 전체를 제공하고, 긴 원문은 최대 4,000토큰의 chunk를 선택한다. 이번 근거는 262~1,271토큰으로 모두 전체 본문 전략이었으며 이 3건에는 추가 수집 없이 설명에 필요한 사실이 있었다. 피드 fallback에는 같은 깊이를 강제하지 않는다. 선택 근거가 없는 원문은 기존처럼 게시하지 않는다.

현재 HTML 추출은 코드·표·목록의 블록 유형을 기록하지만 코드 내부 줄바꿈·들여쓰기와 표의 셀 경계는 완벽히 보존하지 않는다. 정확한 구문을 확인할 수 없는 코드·설정 예시는 재구성하지 않는 것이 기준이다. 복잡한 코드 중심 기사는 별도 추출 품질 점검이 필요하며, 이번 작업에서 수집/추출 로직이나 토큰 예산을 변경하지 않았다.

## 렌더링과 호환성

기존 `title`·`sidebar_label`·서비스/날짜/카테고리 메타데이터와 원문 링크를 유지한다. 동적 소제목·목록·표·인용·코드를 보존하되 HTML·MDX 표현식·import/export는 실행되지 않는 텍스트로 만든다. 본문의 모델 생성 링크/이미지는 비활성화하고 원문 이동은 Generator의 공식 출처 링크가 담당한다. 예전 `summary_ko`만 있는 문서와 draft 출력은 호환한다.

실제 생성 예시: [DiffusionGemma 아티클](examples/dynamic-article.md). 예시 문서는 제품 아카이브나 `briefed_articles` 상태에 등록하지 않았다.
